## 背景

Cerebras 的 WSE-3 (Wafer Scale Engine) 是目前唯一的量产晶圆级 AI 芯片。在快速 token 生成成为推理核心需求的趋势下，Cerebras 获得了 OpenAI 价值数百亿美元的推理计算订单，并启动 IPO。

## 核心架构特点

### 晶圆级设计
- 整片晶圆作为一个芯片，无需 chip-to-chip 互联
- 片上 SRAM 巨大（~44GB），完全消除 off-chip memory 瓶颈
- 没有 HBM，没有 CoWoS，不依赖 TSMC 先进封装产能

### 推理优势
- **极低延迟**：数据全程在片上流动，无 PCIe/NVLink 往返
- **确定性延迟**：单级 SRAM scratchpad 架构，无缓存 miss
- **高吞吐**：适合超大规模批处理推理

### 经济性
- 不需要昂贵 HBM 和先进封装 → 理论成本优势
- 但晶圆良率是核心挑战 — 整片晶圆任一缺陷即报废
- OpenAI 750MW 订单：验证了大规模部署的经济可行性

## 与 GPU 对比

| 维度 | Cerebras WSE | Nvidia GPU |
|------|-------------|-----------|
| 延迟 | 极低（片上全流程） | 受限于显存带宽 |
| 吞吐 | 高批处理场景强 | 灵活性强 |
| 模型适配 | 需要模型 fit 片上 SRAM | 任意规模（offload 到 HBM） |
| 生态 | 自研编译器 | CUDA 生态完善 |
| 产能 | 不受 CoWoS 限制 | HBM+CoWoS 双瓶颈 |

## 产业影响

- OpenAI 的深度绑定验证了"快速 token"的商业模式
- 200G 光 DSP + N3 产能短缺背景下，Cerebras 不受这两重约束
- 晶圆级芯片可能成为推理专用硬件的第三条道路（GPU / TPU / WSE）
