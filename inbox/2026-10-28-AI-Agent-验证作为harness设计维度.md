# 把「验证」当成 harness 的一个设计维度：独立评审是最划算的一档
- 来源: https://arxiv.org/abs/2610.34577
- 日期: 2026-10-25
- 标签: #AIAgent #Harness #验证 #TestTimeScaling

## 摘要
arXiv 2610.34577 把 agent 的验证环节拆成四层——初始指令、轮内提醒、完成闸门（completion gate）、独立评审——在 7 个前沿编码模型、17 种设计上做实测对比（Terminal-Bench / SWE-bench Verified，另建 VisualBench），结论是：指令与提醒收益有限且依赖模型，完成闸门收益大但代价高，独立评审在准确率-成本上最划算。

## 要点
- 独立评审（critic 独立看产物、不能改文件）：TB 平均 +5.9~9.5pp（成本 1.13~1.25x），SWE +3.9~6.6pp（成本 1.00~1.04x，几乎免费）
- 完成闸门（completion gate）能拿更大增益，但 token 成本显著上升——不是默认该开的开关
- 初始指令 / 轮内提醒：平均增益小且随模型波动，别把它们当可靠性手段
- 可叠加：多轮评审或多个独立 critic 再涨 TB 平均最高 3.5pp；VisualBench 上独立评审净偏好 +13.2~23.8pp，压过 L0-L2 设计
- 与 [[AI-Agent-2026格局]] 里「验证器共演化 / 奖励黑客」的线索对齐：花预算在“谁来看产物”比花在“怎么说要求”更值
