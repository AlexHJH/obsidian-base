# KVSET：把「KV cache 工作集」变成在线可测的容量规划量

- 来源: https://arxiv.org/abs/2609.27746
- 日期: 2026-09-23
- 标签: #KVCache #推理引擎 #容量规划 #论文 #agentic

## 摘要
arXiv 2609.27746（Luchang Li 等，9/23）给出 KV cache 工作集的定义：达到目标命中率所需的最小缓存容量。prefix caching 对 agentic 负载（会话与工具历史不断增长、反复调用同一模型）是刚需，但「把历史 KV 全留着」代价过高且往往不必要，而给少了命中率会显著塌方；问题是按容量逐档模拟的常规做法既费算力又费内存，做不了在线分析。

## 要点
- 方法：用 Mattson stack algorithm 一次算出各容量下的命中率 —— 对每个 KV 页计算其 LRU 栈距离，再与各候选容量的页数比较，即可判定该页在该容量下是否命中，无需为每个容量配置独立模拟
- 由「达到目标命中率所需前缀页的最大 LRU 深度」直接反推最小缓存容量，把经验参数变成可测指标
- 验证：用生产 LLM 负载 trace 采集，估计值与真实缓存部署的测量吻合；实现开源，同时支持在线请求处理与离线 trace 回放
- 读法：KV 分层/卸载方案（[[HBF-NAND-AI推理内存2026]] 的 SALT-KV、vLLM 多级 KV 卸载）缺的正是「该配多大」的独立判据
