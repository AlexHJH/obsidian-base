# PyTorch-Triton 3.7 插件扩展系统：TLX 与自定义 Pass 免 fork 落地
- 来源: https://pytorch.org/blog/triton-plugin-extensions-enabling-tlx-and-custom-compiler-passes-out-of-the-box
- 日期: 2026-07-15
- 标签: #AI编译器 #Triton #MLIR #TLX #PyTorch

## 摘要
PyTorch-Triton 3.7 引入 Plugin Extensions，允许运行时动态加载自定义编译 Pass、Dialect 与 DSL 扩展，无需 fork 或重编译上游。Meta 的 TLX 成为首个受益者，以 `triton-utlx` 轮子发布，性能持平甚至超过原 fork。

## 要点
- 三级扩展：①自定义变换 Pass ②自定义 MLIR Dialect + 转换 Pass（TLX 即此类，含 local_alloc/PingPong 等共享内存原语）③顶层自定义 DSL 算子
- 终结"fork 时代"：扩展编译为共享库运行时加载、以 Python wheel 分发，triton-ext 仓库统一管理 backend/dialect/pass/extensions
