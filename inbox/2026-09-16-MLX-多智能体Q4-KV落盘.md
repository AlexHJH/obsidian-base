# 端侧多智能体：Q4 KV Cache 落盘，TTFT 最高降 136x
- 来源: https://arxiv.org/abs/2603.04428
- 日期: 2026-09-16
- 标签: #MLX #端侧推理 #KVCache #量化 #多智能体

## 摘要
arXiv 2603.04428 在 Apple M4 Pro 上做多智能体推理：10.2 GB cache 预算下 FP16/8K 上下文只装得下 3 个 agent，每次驱逐都要整段 re-prefill（4K 上下文 15.7 s/agent）。论文把每个 agent 的 KV cache 以 4-bit 量化存盘（safetensors block pool），重载时直接灌回 attention 层，省掉 O(n) prefill。

## 要点
- 收益：TTFT 最多降 136x（Gemma 3 12B，4K–32K 区间 22–136x）；DeepSeek-Coder-V2-Lite 11–76x；Llama 3.1 8B 24–111x
- 容量：Q4 让固定设备内存里装下的 agent 上下文数变 4 倍
- 质量：用真实 Q4 cache 测困惑度，Gemma -0.7%、Llama +2.8%、DeepSeek +3.0%（非模拟量化）
- 工程空位：mlx-lm v0.30 不提供 quantized KV 的批推理，论文自建 BatchQuantizedKVCache（merge / update_and_fetch / extract）
