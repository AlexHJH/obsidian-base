# ML-Triton：Triton 多级编译与语言扩展
- 来源: https://arxiv.org/abs/2503.14985
- 日期: 2026-06-22
- 标签: #AI编译器 #Triton #MLIR #Intel #多级编译

## 摘要
Intel 团队提出 ML-Triton，扩展 Triton 语言与编译流程为多级 lowering：从 workgroup 级逐步降到 warp 级与 intrinsic 级，匹配 GPU 层次化结构。当前 Triton 直接从 workgroup 降到 per-thread，缺乏中间层级表达力。

## 要点
- 多级编译：workgroup → warp → intrinsic，对齐 GPU 硬件层次
- 支持用户设置编译器 hint，扩展编程接口与可调旋钮
- 面向 LLM 核心算子 GEMM / MHA 等密集运算
- 对比传统 CUDA/SYCL 低层接口，Triton DSL 更可移植、更友好
