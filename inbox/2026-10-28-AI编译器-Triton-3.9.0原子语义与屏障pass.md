# Triton 3.9.0 发布：原子语义补全，屏障插入重写为独立 pass
- 来源: https://github.com/triton-lang/triton/releases
- 日期: 2026-10-27
- 标签: #Triton #AI编译器 #GPU #上游进展

## 摘要
Triton 3.9.0（v3.9.0，10-27 tag）补齐了原子操作的语言层与内存序语义，并把屏障插入（barrier insertion）从散落在各处的补丁重写成独立 pass，同时修掉一批 NVIDIA 后端 miscompile；对下游后端（含非 NVIDIA 目标）来说，语义契约比性能数字更值得跟。

## 要点
- 新 API：`tl.atomic_load` / `tl.atomic_store`（默认 acquire / release）、`tl.atomic_poll`（等值自旋+超时返回 False）、`tl.fdiv(..., approx=True)` 快除法
- 内存序落地：acquire/release/acq_rel 原子现在插 CTA 级 barrier，RMW 与 CAS 默认 acq_rel，要省 barrier 得显式 `sem="relaxed"`
- 屏障插入独立成 pass：补缺失屏障/围栏、删冗余，改动面极大（30+ PR），是移植到新目标时最关键的一条
- 性能/正确性：NVIDIA batched MMAv2 dot 最高快 40x；深层嵌套循环（深度 8）编译约 10x 快；unaligned TMA（非 128B 对齐 per-stage buffer）错结果修掉；multi-CTA 补上 cluster 同步与 proxy fence
- 语义变更（会改结果）：E8M0 的 `0x00` 现解码为 2^-127、`0xFF` 为 NaN（原为 0 / inf）；ConSan 竞态检测更快（约 2.5x）且误报更少
