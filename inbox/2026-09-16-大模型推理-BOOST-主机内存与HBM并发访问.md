# BOOST：让 LLM 推理同时并发使用主机内存与 HBM 带宽
- 来源: https://arxiv.org/abs/2609.13592
- 日期: 2026-09-11
- 标签: #大模型推理 #显存分层 #vLLM #内存带宽

## 摘要
现有 serving 把主机内存当 HBM 的容量后备：数据装得下就只用 HBM，装不下就预取——而预取会占用 HBM 写带宽。BOOST 让同一波 GPU threadblock 同时按带宽比例访问两层，把主机内存带宽真正用起来，且不改 kernel。Grace Hopper + vLLM 上等 batch TPOT 提升 4.3%（预取反而退化 6%），高吞吐场景吞吐 +31%、比预取高 15%。

## 要点
- 关键洞察：要吃到两层带宽，需每波 threadblock 并发访问两层且比例对齐带宽比；既有「按带宽比例放置」策略不感知 GPU wave，又被 2MB 大页粒度拖累
- 实现：静态权重用 modulo 页放置消除访问比例方差；动态 KV 页池做 wave-aware 管理
- 作者：MIT（Saxena / Ju / Taneja / Kozyrakis / Qureshi 等，NVIDIA 与 VMware 参与）
- 对分层内存的意义：DDR / HBF / CXL 不是「容量后备」，而是可并发共享的带宽资源——与 [[HBF-NAND-AI推理内存2026]] 的「HBF 不可 drop-in 当 SSD 平替」互为对照
