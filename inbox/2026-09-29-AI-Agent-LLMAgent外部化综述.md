## 摘要
上交大联合中山大学、CMU、OPPO 的 54 页综述用「认知外部化」统一解释近年 agent 架构演进：能力载体从权重（2022–23）→ 上下文（2023–24）→ Harness（2024 起）三次外移；记忆、技能、协议、Harness 四条线本质是同一件事——把认知负担从模型内部搬到外部结构。

## 要点
- 三种错配对应三种外化：连续性错配 → 记忆（把「回忆」变「检索」）、一致性错配 → 技能（把「即兴生成」变「组合复用」）、协调性错配 → 协议（把「临时约定」变结构化契约）
- 记忆分四层（工作上下文 / 情景经验 / 语义知识 / 个性化），架构从单体式 → 检索式 → 分层编排 → 自适应；关键在于「对的时候调出对的东西」而非存了多少
- 技能是可复用程序性知识（操作程序 + 决策启发 + 规范约束），四条生成路径：人工编写 / 轨迹蒸馏 / 自主发现 / 组合构建，核心机制是渐进披露（先摘要、按需展开）
- Harness 六维：循环与控制流、沙箱隔离、人类审批门控、可观测与结构化反馈、声明式权限策略、上下文预算管理——Codex 与 Claude Code 在此收敛
- 风险提示：记忆→技能→记忆的自强化回路会放大被污染的错误，单模块质控拦不住级联，必须在 Harness 层治理
