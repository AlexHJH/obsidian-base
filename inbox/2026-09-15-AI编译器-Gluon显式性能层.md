# Gluon：Triton 栈上的显式性能编程层
- 来源: https://www.lei.chat/posts/gluon-explicit-performance
- 日期: 2026-02-28
- 标签: #Triton #MLIR #GPU编程 #Kernel

## 摘要
Gluon 是 Triton 官方新增的 GPU 编程语言/前端，直接对接 Triton 编译栈中的 GPU 层 IR（ttg），把原本由编译器隐式决定的布局、共享内存、异步与 warp 分工交给开发者显式控制，用可移植性换性能上限。

## 要点
- 四个暴露点：① 显式 layout（张量元素在 tile 架构上的分布，避免 tl→ttg 转换里不该出现的 layout conversion）② 显式 shared memory 管理（`shared_memory_descriptor` API，Triton 只能间接调 buffer 数量）③ 架构特定特性（Gluon kernel 不再跨厂商可移植）④ 显式 warp specialization API（Triton 只能在 block 层编程、所有 warp 走统一控制流）
- 动机是硬件演进：Ampere→Hopper→Blackwell 越来越异步，TMA 等专用单元要求把 SM 内各流水线喂满，靠编译器静态排布指令很难，不如让硬件动态调度 + 开发者显式分工
- 生态对照：PyTorch 侧 autoWS（自动 warp specialization）在 B200 FlashAttention 上接近 Gluon/cuDNN，达 stock Triton 的 1.5–2x，但仍落后 cuDNN 10–20%——显式与自动两条路线并行推进
