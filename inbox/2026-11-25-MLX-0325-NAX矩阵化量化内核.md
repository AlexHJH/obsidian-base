# MLX 0.32.5：量化 matmul 全线搬上 M5 神经加速器（NAX），并暴露可用性查询

- 来源: https://github.com/ml-explore/mlx/releases/tag/v0.32.5
- 日期: 2026-11-25
- 标签: #MLX #AppleSilicon #M5 #NAX #量化 #Metal

## 摘要
MLX 0.32.5 于 2026-11-25 07:24 UTC 发布（v0.32.4 之后约六周），上百条 PR 的主体是量化矩阵乘内核的系统性矩阵化改写。同一版里第一次把「这台机器到底走不走 NAX」变成 Python 可查询的事实，而不是靠猜。

## 要点
- 语义前提：NAX 是 M5 GPU 每个核内新增的专用矩阵乘单元，经 Metal 4 的 TensorOps / `mpp::tensor_ops`（`matmul2d`，simdgroup 或 threadgroup 集体发起）访问；MLX 是 Apple 自家在这条路径上的参考实现
- 本版内核族：`affine_qmm_t_nax` + split-k、`fp_qmm_t_nax`、`qmv_mma`/`qmv_nax`（3–16 行、大 N/K）、`affine_qmv_mma` 扩到 2/3/5/6 bit 且覆盖 M1/M2 Ultra、M3 Ultra；fp4→half 反量化加快速分支
- 可验证性：新增「Expose NAX kernel availability to Python」，不再需要翻 Metal 后端源码判断分派是否命中矩阵单元
- 低行数 qmv/qmm 覆盖的是 decode 形状的 GEMV——这版不只补 prefill GEMM，也在为单请求解码铺 mma 路径（推断，非原文）
- 非 NAX 设备同时受益：M1/M2 的 `sdpa_split`（面向投机解码）、head_dim 256 的融合 SDPA（512–1023 query 行）、f16 向量 SDPA
- 模型侧：新增 sliding window attention，RoPE 支持 `freqs` 与 `partial_rotary_factor`
- CUDA 后端继续补齐（CUDA graph、128 行 qmm、>2^31 元素输出溢出修复）并新增 `cuda.get_arch_list()`，已不是 Metal 的陪跑
- 工程化：可关闭 Metal 运行时编译、CPU JIT cache 目录可配、macOS 27 构建、TSan/UBSan 抑制表、`__array_api_version__`
- 读法：这是补丁号发布，多数改动是「修对/扩覆盖」而非「变快」；NAX 仅在 M5 + 新 macOS 生效，其余设备无感
