# OSDI '26 最佳论文：LLM 预训练数据管线优化（USTC × 字节 Seed）
- 来源: https://en.ustc.edu.cn/info/1007/5181.htm
- 日期: 2026-08-22
- 标签: #OSDI #系统顶会 #LLM训练 #数据管线

## 摘要
第 20 届 USENIX OSDI（2026-07-13~15 西雅图）上，中科大李诚团队联合字节跳动 Seed 凭 "Teaching The Old Dog New Tricks: Building Efficient Data Pipelines for Large-Scale LLM Pre-training" 获 Jay Lepreau 最佳论文奖。基于 3 万余训练任务的真实生产数据，首次系统揭示 LLM 预训练数据管线三大瓶颈并给出三项优化。

## 要点
- 三大瓶颈：伴生评测引发的跨数据中心流量、启动阶段初始化 I/O 风暴、多模态数据变换的 CPU 密集瓶颈
- 三项优化：预测性 checkpoint 复制、主动热文件复制、存储侧数据变换卸载
- 同期 OSDI '26 另有多个最佳论文：厦大 ValScope（DBMS 逻辑缺陷蜕变测试）、布朗大学 Semisolates；OpGuard（LLM 训练调试）获最佳论文提名
- 信号：数据管线正成为继算力/通信之后的大模型训练新优化焦点
