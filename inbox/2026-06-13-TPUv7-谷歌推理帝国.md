## 背景

Google TPU 已成为仅次于 Nvidia GPU 的全球第二大 AI 加速器平台。TPUv7 在架构和部署规模上都达到了新高度，Anthropic 签约超 100 万颗 TPU 用于推理。

## 核心架构特点

### ICI (Inter-Chip Interconnect) — TPU 的灵魂
- TPU 不使用 NVLink/InfiniBand 等传统网络
- 自研 ICI 互联：芯片间直连 torus 拓扑
- 单个 ICI 域可连接 9,216 颗 TPU — 远超 NVLink 域规模
- 配合 Paloma OCS (光电路交换机) 实现机架级互联

### 系统 > 微架构
- SemiAnalysis 核心理念：Google 的优势不在单芯片，而在系统级整合
- 从微架构到系统架构的全栈控制 → perf/TCO 优势
- 关键对比：Microsoft/Amazon 依赖外部供应商，整合度不如 Google

### 与 GPU 的关键差异

| 维度 | TPUv7 | Nvidia GPU |
|------|-------|-----------|
| 互联 | ICI torus (9216 芯片/域) | NVLink (72 GPU/域) + IB |
| 内存 | HBM，容量优先 | HBM，带宽优先 |
| 编程 | JAX/Pallas | CUDA/Triton |
| 推理优化 | 编译器驱动的 layout 优化 | kernel 手写 + 编译器 |
| 客户 | Google + Anthropic | 全行业 |

### 推理部署策略
- TPU 的强项在推理（而非训练）
- Google Cloud TPU 通过编译器自动优化模型 layout
- Pallas kernel 语言允许手写底层 kernel（类似 CUDA 但更简洁）

## 产业影响

1. Anthropic 的 100 万 TPU → 验证 TPU 作为第三方推理平台成熟度
2. 推理市场的碎片化趋势：GPU / TPU / Trainium / Cerebras 共存
3. 编译器和软件栈成为差异化关键，纯硬件指标不再是唯一标准
