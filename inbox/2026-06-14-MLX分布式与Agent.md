# WWDC26: MLX 分布式推理与本地 Agentic AI
- 来源: https://developer.apple.com/videos/play/wwdc2026/233
- 日期: 2026-06-14
- 标签: #MLX #WWDC2026 #分布式推理 #Agent

## 摘要
WWDC 2026 苹果展示了 MLX 两项关键能力：通过 Thunderbolt RDMA 实现多台 Mac 分布式推理（4×M3 Ultra 跑 27B 模型吞吐近 3x），以及全本地 Agentic AI 栈（MLX + MLX-LM + MLX-LM Server + Agent 层），支持 OpenCode 等代码 Agent 完全离线运行。

## 要点
- 分布式栈：RDMA over Thunderbolt → MLX → MLX-LM，一条 CLI 命令即可分片推理
- Agent 四层架构：MLX(数组框架) → MLX-LM(模型加载/量化/微调) → MLX-LM Server(OpenAI 兼容) → Agent
- 支持 Tensor Parallelism 和 all_reduce 原语，JACCL 可独立用于非 ML 分布式负载
- 与 Ollama/LM Studio/vLLM 等工具生态兼容，本地 agent 零延迟、隐私保护
