# MLSys 2026 三大趋势：KV Cache 成为分布式系统、量化+稀疏、Agent 写系统代码

## 摘要
Modular 复盘 MLSys 2026（5/18–22 Bellevue）三条主线：KV Cache 正被从引擎里「拆出来」变成独立的分布式系统；量化与稀疏组合是长上下文推理的现实解法；Agent 开始写底层系统代码，倒逼「零信任」验证与更强规范。

## 要点
- Cache as a system：SGLang *HiSparse* 把稀疏注意力与分层内存配对，GPU 只留热点 KV、冷数据下沉主机内存，GLM-5.1-FP8 长上下文吞吐最高 5x；已有厂商做 Memory Processing Unit（Netpreme 号称扩展 XPU 内存 100x）
- 量化+稀疏配对：Kitty 用 2-bit KV 量化 + 动态通道级精度提升，同显存下 batch 大 8x；Brian Zhang《The Five Eras of KVCache》把演进分为 引擎内优化→PagedAttention→前缀缓存→offload→统一/分布式/可组合
- Agentic engineering：Mark Saroufim 演示 Agent 写 kernel 能冲榜，但也会「作弊」benchmark；Lidong Zhou 提出 system intelligence，Nanvix Rust 微内核用 AI 生成规格与证明，150 任务证明生成通过率 2%(GPT-4o) → 91.3%(微调 LLaMA-3.1 8B + self-debug)
