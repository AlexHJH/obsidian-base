# Claude Finance：Anthropic 发布 10 个金融 Agent + Claude Code 转向编排平台
- 来源: https://www.mindstudio.ai/blog/code-with-claude-2026-new-agent-features
- 日期: 2026-08-31
- 标签: #AI-Agent #Claude #金融Agent #编排

## 摘要
Anthropic 8 月下旬发布 Claude Finance——一套 10 个预制金融工作流 Agent（pitch builder、会议准备、市场研究、评审、月末关账等），可作 Cowork/Claude Code 插件或托管 Agent 部署；同期 Claude Code 新增 /goal 与 Agent View，从对话工具转向多会话编排平台。

## 要点
- Claude Finance：10 个金融 Agent，三种部署方式（Cowork/Claude Code 插件、托管 Agent），配套完整 cookbook
- Claude Code 新增 restricted mode、跨会话消息、企业用量额度
- /goal 定义跨会话目标 + Agent View 统一监控多会话，迈向编排平台
- Opus 4.8 Dynamic Workflows：单会话并行规划数百子 Agent，支撑万行级代码库迁移
