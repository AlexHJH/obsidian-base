# Apache TVM v0.26.0 发布：TIRx 从 bring-up 转入收尾（typed buffer / op-dispatch / gemm-async）
- 来源: https://github.com/apache/tvm/issues/20099 ; https://github.com/apache/tvm/releases ; https://lists.apache.org/thread/9wpyfgygh8jnw3hvr29tnss9m97pmx3r
- 日期: 2026-10
- 标签: #AI编译器 #TVM #TIRx #MLIR

## 摘要
TVM 发布 v0.26.0（v0.27.0.rc1 已进入预发布投票）。0.26 的重点是 TIRx 落地：buffer 升级为带类型的变量（BufferType）、新增一等公民 Return 语句；0.27 转入 bring-up 收尾，做 op-dispatch、namespaces、launch bounds、gemm-async 与 backend 重组。

## 要点
- op-dispatch + namespaces 让不同硬件注册自己的分派规则，正是「Agent 按硬件生成特化编译逻辑」所需的接口层
- launch bounds / gemm-async 说明调度约束与异步搬运已进入内核 DSL 原语层，而不只是编译器内部 pass
- 工程侧：Python 依赖 apache-tvm-ffi 下限提到 ≥0.1.13.post2；修复 Z3 context 隔离与 MSVC 构建
- 日期口径：未读到官方 0.26.0 发布公告原文，仅据投票帖 / releases 页判断为 2026-10，属推断而非实测
