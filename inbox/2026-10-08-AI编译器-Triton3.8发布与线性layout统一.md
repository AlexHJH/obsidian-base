# Triton 3.8.0 发布；官方宣布 layout 统一到 linear layout
- 来源: https://github.com/triton-lang/triton/releases ; https://pytorch.org/blog/triton-kernel-compilation-stages
- 日期: 2026-10-08
- 标签: #AI编译器 #Triton #MLIR #GPU

## 摘要
Triton 3.8.0 于 8/28 发布，Gluon 与 layout 仍是改进重点。更关键的是官方在最近一届 Triton 大会上宣布：把此前分散的 block/共享内存 layout 表示统一为 linear layout，目标是让 NVIDIA 与 AMD 后端共用同一套 layout 代数。

## 要点
- 统一收益：线性 layout 可把一部分 layout 转换「证明为恒等」，从而被 RemoveLayoutConversionsPass 直接消掉——减少跨 SM / 共享内存的数据搬运
- Gluon 侧继续补齐 `to_linear_layout`、`SharedLinearEncoding`、`PaddedSharedLayouts` 等能力，把显式性能控制下沉给用户
- NVIDIA 后端围绕 Blackwell 补 tcgen05 相关 op、TMA 与 warp-specialization（tt.split/join）
- 版本节奏仍绑定 PyTorch：每两个 minor 从 main 取一次 commit，故 3.8 号段不等于新特性集合
