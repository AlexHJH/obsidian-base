# Apache TVM 发布 TIRx：面向前沿 ML Kernel 的开源编译器栈
- 来源: https://tvm.apache.org/2026/06/22/tirx
- 日期: 2026-06-22
- 标签: #AI编译器 #TVM #TIRx #ML-Kernel #开源

## 摘要
Apache TVM 项目发布 TIRx，一个硬件原生 DSL 和编译器，专为前沿 ML kernel 设计。采用 storage-first tensor layout，编译目标覆盖 GPU 和专用 AI 加速器，同时支持人工编写、Agent 生成和 megakernel 三种 kernel 开发范式。

## 要点
- 极简编译器栈，构建于 TVM 之上，面向快速迭代的 kernel 和硬件
- storage-first 设计：显式控制内存布局和线程分配，兼顾性能与可移植性
- 三大场景：专家手写 kernel、AI Agent 生成 kernel、megakernel 系统
- 设计哲学：随硬件代际演进持续适配，避免被特定架构锁定
