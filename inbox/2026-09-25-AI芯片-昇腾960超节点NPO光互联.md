# 华为昇腾 960 超节点：业界首个 NPO 光引擎超节点，4096 卡 / 8E FP8 / 1PB HBM

- 来源: https://www.huawei.com/cn/news/2026/9/hc-ascend960-supernode
- 日期: 2026-09-17
- 标签: #AI芯片 #昇腾 #超节点 #光互联 #NPO #灵衢

## 摘要
华为全联接大会 2026（9/17，上海）发布全球首个采用 NPO（近封装光学）光引擎的超节点——昇腾 960 超节点，基于灵衢 + 自研 NPO 光引擎 Hi-ONE，单超节点 4096 卡、8E FP8 / 16E FP4、最高 1PB HBM。同场宣布昇腾 960 芯片研发提前：960DT 提前三个季度至 2027Q1，960PR 提前一季度至 2027Q3。

## 要点
- Hi-ONE：业界首个量产 NPO 光引擎，单引擎容量 7.2T，唯一内置光源；超节点用 5500 个 Hi-ONE 替代原本 4.8 万颗 800G 光模块 → 功耗降超 550kW、系统无故障运行时间翻倍、可用度 99.8%
- 互连设计理念三句话：一套协议平等连接集群内所有组件、支持跨物理服务器内存访问、**近铜远光**（近距离用铜、远距用光）
- 集群扩展路径：多超节点经灵衢或 RoCE 二级 CLOS 四平面组网 → 最大 51.2 万卡；叠加多轨道拓扑可支持 100 万卡昇腾超节点集群
- 配套通算升级：鲲鹏超节点基于灵衢全光组网最大 4096 节点，形成 256TB 统一内存池，官方口径是给 Agent 更高密沙箱、更快沙箱启动与更好向量检索性能；另发 L3.5 层 PB 级 KV 缓存方案 OceanStor M900（灵衢一跳直连）
- 现状数据：昇腾 910C 超节点累计部署超 1000 套，昇腾 950 超节点已规模商用；后续昇腾 970（2028）、980（2029）保持一年一代
- 与 [[#平头哥真武 V900]] 对照：两家国产算力同日前后把主战场从单卡算力搬到「超节点域能做多大 + 域间怎么组网」，光互联与统一内存编址成为共同关键词
