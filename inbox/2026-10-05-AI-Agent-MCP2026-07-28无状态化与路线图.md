# MCP 2026-07-28 修订版：协议层无状态化，生态破 1 万+ servers
- 来源: https://blog.modelcontextprotocol.io/posts/2026-07-28 ; https://modelcontextprotocol.io/development/roadmap
- 日期: 2026-07-28（Roadmap 更新 2026-08-22）
- 标签: #AI-Agent #MCP #协议标准 #工具调用

## 摘要
MCP 在 7/28 交出协议史上最大一次修订：移除 `initialize` 握手与协议级 session，让 MCP 在协议层变成无状态，每次请求用 `_meta` 自带协议版本与客户端能力；roots、sampling、logging 与旧 HTTP+SSE 传输一并弃用。生态已破 1 万+ 服务器，OpenAI / Google / Microsoft / AWS 均接入自家 agent 栈。

## 要点
- 无状态化：取消 `Mcp-Session-Id` 与 initialize/initialized；跨调用状态改由 server 显式铸造的 handle 当普通工具参数传（SEP-2567）；`tools/list` 等列表不再随连接变化
- Tasks 移出实验核心 → `io.modelcontextprotocol/tasks` 扩展（poll-based `tasks/get` + 新增 `tasks/update`）；通知统一到 `subscriptions/listen`，按类型 opt-in
- 授权收紧：客户端凭据绑定签发方、不可跨授权服务器复用（SEP-2352）；DCR 正式弃用转向 CIMD（保留向后兼容）
- 路线图（2026-08-22）：统一 transport（消除 HTTP/stdio 双轨与头字段重复）、面向 agent 身份（云 workload 自持身份、子 agent 收窄权限）的授权模型
- 口径：依据官网 changelog/roadmap 与媒体转述整理，未逐条跑通 SDK
