# IME 的 ratification 窗口已经错过近三个月，标准停在 ARC 门口，厂商子集先上了 LLVM
- 来源: https://riscv.atlassian.net/wiki/spaces/IMEX/pages/598867969/IME+Ratification+Plan ；https://github.com/riscv/integrated-matrix-extension/releases ；https://llvm.org/docs/RISCVUsage.html
- 日期: 2026-11-11（对照核对）
- 标签: #RISC-V #IME #Zvvm #规范进程 #LLVM

## 摘要
IME 的官方计划把 v0.99 TSC 批准定在 2026-08-17、v1.0 批准定在 2026-08-27；实际仓库最新只到 0.9.0「ARC Review Candidate」（08-24，分支 `zvvm-review-fixes`），release 页明确写 not ratified / not an official release，0.99 未发布。标准没动，生态先动：LLVM 已把 SpacemiT X60/A100 的 IME 子集做进上游。

## 要点
- 时间线对账：计划里 v0.9 冻结 06-27、公开评审 06-27 起、0.99 于 08-17、1.0 于 08-27；实际 v0.9 Freeze release 到 08-10 才出，0.9.0 候选 08-24 → ARC 书面评审与 GC 投票是唯一卡口
- 版本阶梯仍是 0.9 → 0.9.0 → 0.99 → 1.0，当前对外可引用的最高版本就是 Freeze 0.9（Zvvmm/Zvvfmm/Zvvmtls/Zvvmttls）
- LLVM 上游现状：`XSMTVDot`（X60）与 `XSMTVDotII`（A100）已实现，指令前缀 `smt.`，文档自述为 SpacemiT Vector Dot Product Extension 1.0.0、严格是完整 IME 的子集
- 社区在往「一条 lowering」收敛：LLVM Dev Meeting 2026 有 "Bringing RISC-V Matrix and Vector Vendor Extensions into MLIR-based ML Compilers"（Roofline/Ege Beysel），Summit Europe 也明说 IME 与 VME 开始合并到共同的 LLVM-MLIR 路径
- 判读：ratified 与否已不是落地门槛，厂商子集先进编译器。对 Triton/VME 后端，可对齐的实参是这几个子集与共同的 MLIR 路径，不是 0.9 全文
- 口径：来自计划页里程碑表、release 页与 LLVM 文档三处交叉；未收到任何 ratified 公告，若 11 月内批准以官方 release 为准
