# NVIDIA Nemotron 3.5 Lightning：面向 Agent 的快速 worker 模型

- 日期: 2026-08-23

## 摘要
NVIDIA 8/11 发布 Nemotron 3.5 Lightning（30B 总参/3B 激活 MoE），定位长程 Agent 的快速 worker 模型，vLLM 实现 Day-0 支持。内置多 token 预测（MTP）投机解码默认开启，实测吞吐 1.46–1.96×，GPU 单 token 成本近乎减半。

## 要点
- 30B-A3B MoE、NVFP4 量化、OpenMDW 1.1 许可，8/11 发布
- 原生 MTP + DFlash + DSpark 投机解码默认开启，Thoughtworks 2091 次实测（H200/B200）吞吐 1.46–1.96×
- 定位长程 Agent/子 Agent worker：执行工具调用、校验输出等"执行类"工作，省前沿模型成本
- 成本 $0.477 → $0.250/百万输出 token；vLLM OpenAI 兼容栈 Day-0 部署，支持本地/企业
