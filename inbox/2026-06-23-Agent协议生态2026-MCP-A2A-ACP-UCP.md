# 2026 Agent 协议生态全景：MCP / A2A / ACP / UCP 四大协议

## 摘要
截至 2026 Q1，Agent 互操作领域已形成四大协议并存的格局：MCP（Anthropic，工具调用）、A2A（Google，Agent 间通信）、ACP（IBM/BeeAI，Agent 运行时管理）、UCP（统一上下文协议）。每个协议解决 Agent 栈中不同层次的问题，彼此互补而非竞争。

## 要点
- **MCP**（2024.11 Anthropic）：Agent↔工具标准化接口，JSON-RPC 双向通信，已成事实标准
- **A2A**（2025.04 Google）：Agent Card 数字名片 + 任务发现委托，跨厂商 Agent 协作；2026 升级支持 AI Agent Marketplace 直接售卖
- **ACP**：IBM/BeeAI 主导，聚焦 Agent 运行时生命周期管理与编排
- **UCP**：统一上下文协议，解决多 Agent 共享上下文的一致性问题
- 协议栈分层：MCP(工具层) → A2A(协作层) → ACP(运行时层) → UCP(上下文层)
