## 摘要
Alice Labs 基于 18+ 次生产部署发布 Q2 2026 Agent 框架排名。LangGraph 1.0 以 per-node timeouts + DeltaChannel 居首，Claude Agent SDK（6月新增层次化子 Agent 生成）和 CrewAI 1.14（可插拔后端）紧随其后。Pydantic AI V2 和 LlamaIndex Workflows 1.0 均在 6月下旬正式发布。

## 要点
- LangGraph 1.0 新增 per-node 超时控制、DeltaChannel 和 v2 streaming，稳居综合第一
- Claude Agent SDK (2026-06) 支持层级子 Agent 生成 + 降级模型链，适合 Anthropic 原生场景
- CrewAI 1.14 (5-6月) 新增可插拔后端 + Chat API，角色式多 Agent 原型最快路径
- Pydantic AI V2 (6/23) 和 LlamaIndex Workflows 1.0 (6/22) 同日发布，分别主打类型安全和 RAG Agent
