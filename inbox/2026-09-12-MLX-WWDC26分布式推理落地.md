# WWDC26：MLX 分布式推理落地（Thunderbolt RDMA + 张量/流水线并行）
- 来源: https://developer.apple.com/videos/play/wwdc2026/233
- 日期: 2026-09-12
- 标签: #MLX #Apple-Silicon #分布式推理 #RDMA #并行

## 摘要
WWDC26 首次展示 MLX 分布式全栈：macOS 26.2 起支持 Thunderbolt RDMA，通信库为 JACCL，MLX / MLX LM 提供张量并行（默认，按宽度切）与流水线并行（`--pipeline`，按深度切）。4 节点最高约 3 倍生成加速，可运行单机装不下的万亿参数模型。

## 要点
- 张量并行能加速，但每层每 token 都要通信，因此依赖单跳全互联（网格拓扑）；流水线并行通信少但不加速，只解决"装不下"
- 万亿参数 Kimi 2.6：8-bit 仅权重就约 1TB，单台 M3 Ultra 放不下，4 台可分片运行
- 使用极简：`mlx.launch` + hostfile，模型自动分片，CLI / Python / Swift / C++ 均支持
- 对 agent 工作流的意义：跨机并行化 prefill，直接加速"读取工具输出"这一环
