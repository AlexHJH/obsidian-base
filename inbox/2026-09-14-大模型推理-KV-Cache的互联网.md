# 为 KV Cache 建一个「互联网」：把网络与存储当一级推理资源
- 来源: https://arxiv.org/abs/2608.01526
- 日期: 2026-08-02
- 标签: #大模型推理 #KV缓存 #论文 #数据中心网络

## 摘要
Siddhant Ray、Nick Feamster、Junchen Jiang 提出：LLM 推理已变成跨云、跨数据中心的全局负载，上下文复用让 KV Cache 值得存储与搬运，但模型侧压缩与系统侧降本各自演进、被存量云边界割裂。主张解耦计算与 KV 存储，让带宽/延迟/定价直接进入 KV 管理决策。

## 要点
- 认知转向：KV Cache 复用把推理从「算力-存储权衡」升级为「互联网级内容分发」，推理端只是 CDN 上的一个节点
- 联合决策三要素：模型指标（命中率/压缩率）+ 基础设施指标（带宽/延迟/价格）+ 应用指标（SLO/请求模式）共同决定 recompute / store / reuse
- 割裂现状：Mooncake、LMCache、HiCache 等 KV 层与模型侧 KV 压缩进展互不相通，缺少跨边界抽象
- 待建能力：新的度量、抽象与架构，把网络与存储从被动管道变成主动可调旋钮
