# 定位隐藏失败：4B 验证器让长任务 Agent 更可靠（arXiv 2609.17930）

- 来源: https://arxiv.org/abs/2609.17930 ; https://arxiv.org/html/2609.17930
- 日期: 2026-09-15
- 标签: #AIAgent #长任务 #验证器 #可靠性 #失败定位

## 摘要
核心动作是把一条长轨迹当成「待检查的决策序列」：人工只标注**第一个错误**，再训练一个 4B 验证器自动定位失败步骤，并用它在多个候选 run 间做选择。失败因此变得便宜可定位，任务成功率随之提升——作者把它定位为让长任务 Agent 从自身失败中学习的基础设施。

## 要点
- 现象：长任务 Agent 几乎抓不住自己的第一个错误，错误沿轨迹传播 → 定位比生成更稀缺
- 方法：轨迹 = 决策序列；人工只标 first mistake（低成本标注），训练 4B 验证器学习定位
- 一物两用：验证器既定位失败步，也在候选 run 之间做选择（best-of-n 的判别器）
- 结论口径：把「定位失败」做成廉价能力，就同时获得纠错与选优 → 更可信的长任务 Agent
- 与主线一致：瓶颈在「验证独立于生成」，不是再多采样几次
