# Long-Horizon Terminal-Bench：长时程 Agent 的真实瓶颈是「撑不住」，不是「不会做」

- 来源: https://zli12321.github.io/LHTB
- 日期: 2026-07-13
- 标签: #AI-Agent #长时程 #基准评测 #验收

## 摘要
腾讯 HY LLM Frontier 发布 LHTB，用 46 个需 1 小时以上、上百步工具的终端任务测 Agent 的「可持续推进能力」，并用密集奖励（而非 pass/fail）打分。结论是前沿模型仍只在少数任务上拿到满分，且绝大多数失败是任务没做完，而不是做错。

## 要点
- 单任务均值 69–93 分钟、120–320 步；一次完整评测每模型要跑 53–71 小时墙钟
- 平均每条 run 231 步、9.9M token、85 分钟；最强模型 reward=1.0 仅 7/46（满分率约 11%）
- **79% 未完成 run 是「超时但仍在大步推进」——完成度是容量问题，不是能力问题**
- 成本：平均约 $10/任务，头部模型 >$20/任务；长时程任务的经济性本身就是设计约束
- 对 LongLoop 的启示：密集奖励 + 隐藏 verifier 的度量方式，正好对上「防虚假完成」——只看最终状态的 grader 会把「还在推进」误判成失败或成功
