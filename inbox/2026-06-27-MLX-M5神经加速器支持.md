# MLX 支持 M5 神经加速器，Apple Silicon 推理再提速
- 来源: https://machinelearning.apple.com/research/exploring-llms-mlx-m5
- 日期: 2026-06-27
- 标签: #MLX #AppleSilicon #推理 #M5

## 摘要
Apple 官方机器学习研究博客介绍，MLX 已在最新 macOS beta 中支持 M5 芯片的神经加速器（Neural Accelerators）。这些加速器提供专用矩阵乘法运算，是 ML 推理的关键算力来源，使 Apple Silicon 上的 LLM 推理体验显著提速。文章在 MacBook Pro M5（24GB 统一内存）与 M4 上对比了多种规模架构的 LLM 推理性能。

## 要点
- MLX 是 Apple 为 Apple Silicon 打造的开源数组框架，现已适配全系列芯片
- M5 神经加速器提供专用矩阵乘法硬件，直接利好 LLM 推理 workload
- 官方在 M5 24GB 上对多种 LLM 跑 benchmark，与 M4 同配置对比
- 生态同步：Ollama 0.19（2026-03）加入 MLX backend，mlxcel v0.1.0（2026-05-28）Rust 原生引擎发布
- WWDC 2026 推出 Core AI（Core ML 继任者），与 MLX 在端侧推理形成竞合
