# "KV Cache 互联网"：重构 LLM 推理基础设施边界
- 来源: https://arxiv.org/abs/2608.01526
- 日期: 2026-08-30
- 标签: #MLSys #大模型推理 #KV-Cache #系统架构

## 摘要
arXiv 2608.01526 提出愿景：KV Cache 复用已把 LLM 推理从"算力-存储权衡"变成"互联网级内容分发"问题，主张把网络与存储当作推理的一等资源，为缓存状态建立分布式查找/路由/迁移的控制面。

## 要点
- KV Cache 可重算或复用，最优位置取决于存储-网络-重算权衡，而非云/管理边界
- 控制面需分布式 lookup + 带宽与截止时间估算，决策移动/复制/部分取/重算
