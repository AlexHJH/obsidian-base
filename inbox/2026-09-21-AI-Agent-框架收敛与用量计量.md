# 框架收敛与运行时治理：AutoGen 迁移风险 + agent 用量计量

- 日期: 2026-09-19

## 摘要
9/19–9/20 生态动态主线是「收敛与计量」：AutoGen 进入维护模式后的迁移风险被公开提示，GitLab 与企业框架同时收紧 agent 的模型选择权、技能包校验与用量计量。

## 要点
- Traversaal 9/19 分析：微软框架收敛（AutoGen 维护模式、MAF 为主路径）形成迁移窗口与兼容性风险 → 先审计 agent 依赖与运行时钩子、估算迁移工时，再决定包装现有栈还是主动迁移
- MAF 1.19.0（Python）：MCP 会话按 invocation 隔离、请求绑定正确身份与来源、技能包仅允许 ZIP 且校验摘要 → 直接针对技能包被篡改的供应链风险
- GitLab 19.4：Duo agentic 自动化扩面 + 模型白名单治理 + Credits 用量可见；10/19 起按用户/组计量 agent 流量 → AI 成本从共享池转为 per-user / per-agent 问责
- Google：Gemini API 托管 agent 新增 antigravity-preview-09-2026 harness，并给出 Files / Credentials API（沙箱数据进出 + 让 agent 调 GitHub/Slack 而不把 token 暴露给模型）
- 同期：Swarms 9/19 发 Auto Agent Builder、批量运行（≤500 任务）与 per-completion 永久链接（成本/失败可逐任务追溯）；Forge vnext 加 `forge skills validate` 与默认拒绝治理
