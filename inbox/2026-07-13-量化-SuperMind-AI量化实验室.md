## 摘要
同花顺 SuperMind 平台推出「量化实验室」功能，通过 AI Agent 将自然语言策略描述自动生成为可执行代码并回测。支持 Python 策略（多因子选股）和公式策略（技术指标择时），大幅降低量化投研门槛。

## 要点
- 因子研究 Agent：从研究想法出发自动生成因子表达式并验证
- 策略代码生成：自然语言描述 → Python/公式策略源码 → 自动回测 → 多轮优化
- Python 策略适合 A 股选股/多因子模型，公式策略适合单标的日内择时
