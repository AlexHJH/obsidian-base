## 摘要
2026年AI Agent框架格局已高度分化：LangGraph主导编排、AgentCore(AWS)提供全托管部署、Strands SDK主打轻量工具调用。7月21日Personal AI Agents Summit汇聚OpenAI/Google/Anthropic/Perplexity，聚焦个人Agent安全与生产落地。

## 要点
- 六大主流框架：LangChain、AgentCore(Bedrock)、LangGraph、CrewAI、AutoGen、Strands Agents SDK
- 生产团队趋势：多框架组合——LangGraph做编排，AgentCore做部署，Strands做轻量Agent
- Anthropic 三态安全模型：block/allow/triage，每种策略过度使用都有失败模式
- OpenAI 成立 Deployment Company，派 Forward Deployed Engineers 嵌入客户现场
- MCP 协议已成跨厂商标准，Anthropic 提出后被 OpenAI 和 Google 采纳
