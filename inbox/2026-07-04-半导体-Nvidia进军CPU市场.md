# Nvidia 进军 x86 CPU 市场：2026年出货$20B数据中心CPU
- 来源: https://www.barrons.com/articles/chip-stock-rally-2026-nvidia-amd-broadcom-tsm-micron-df290dbc
- 日期: 2026-07-04
- 标签: #AI芯片 #Nvidia #CPU #Intel #AMD

## 摘要
Nvidia 宣布今年将出货 $20B 独立数据中心 CPU 芯片，规模接近 Intel 数据中心营收。新芯片基于 TSMC 3N 工艺，与 Nvidia GPU 深度协同，挑战 Intel/AMD 在服务器 CPU 市场的长期统治。标志着 AI 芯片巨头向通用计算腹地扩张。

## 要点
- Nvidia 数据中心 CPU 年出货目标 $20B，体量接近 Intel 同期
- 采用 TSMC 3N 工艺制造，与自家 GPU 深度集成
- 从 AI 加速器切入通用计算，三巨头格局加速形成
