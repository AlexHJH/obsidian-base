# Claude Managed Agents 三大新功能：Dreaming 记忆 / Outcomes 评估 / 多代理协调

## 摘要
Anthropic 为 Managed Agents 补齐三大生产短板：Dreaming 让 Agent 空闲时回顾会话、自动提炼模式写入记忆库；Outcomes 引入独立 Grader 模型按「成功标准」客观评估输出；Multi-Agent Orchestration 支持多代理协调。前两者分别以研究预览/公开测试版上线。

## 要点
- Dreaming（研究预览，8/1 起支持 Opus 5）：扫描近期会话 → 识别反复出错、收敛的高效工作流、团队偏好三类模式 → 更新记忆；提供自动/人工审核两种模式
- Outcomes（公开测试版）：独立上下文窗口的 Grader 按 rubric 审输出，避免自我评估偏差，任务成功率 +5~10pp（高难任务 +10pp）
- 定位：直击 Agent 的记忆固化、客观评估、多代理协调三大落地痛点
