# Agent 支付协议兴起：AP2 / ACP / MPP / x402

- 日期: 2026-06-28
- 标签: #AI-Agent #AgenticCommerce #AP2 #支付协议 #MCP

## 摘要
2026 年 Agent 协议栈向支付层延伸：在 MCP/A2A（工具/协作）之上涌现支付协议 AP2、ACP、MPP、x402，让 Agent 从「调用工具」跃迁到「自主完成交易」。

## 要点
- AP2（Google，2025-09，60+ 伙伴）：开放、支付无关，核心=加密签名 Mandate（Intent/Cart/Payment 三类），A2A+MCP 的支付层伴侣，支持卡 + 加密货币（x402 扩展）
- ACP（OpenAI×Stripe）：结账流标准化，ChatGPT Instant Checkout 首用；⚠️ 与 IBM BeeAI 的 ACP 同名不同义
- MPP（Stripe×Tempo，2026-03）：sessions 模型，预授权额度 + 流式微支付（稳定币/法币）；x402（Coinbase）= 加密支付标准
- Adyen Agentic（2026-06-16）：商户一次集成覆盖所有 agent 商业面
