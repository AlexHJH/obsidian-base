# LLM 推理优化全景 (2026)

## 摘要
2026 年 LLM 推理优化已形成三层体系：模型层（量化/剪枝/蒸馏）、系统层（continuous batching/PagedAttention/投机解码）、应用层（上下文压缩/prompt caching）。Agent 工作流每次任务 50-200 次 LLM 调用，放大了推理成本问题。

## 要点
- 典型 API 调用浪费 40-60% 输入 token 在无关上下文上，上下文压缩成为关键优化方向
- vLLM/SGLang 相继公司化（Inferact $1.5亿 / RadixArk $4亿估值），推理引擎走向商业化
- 异构计算（CPU-GPU 显存交换）在探索中，混合场景性能可能下降 28%
