# A2A 协议进入生产规模：150 组织跨平台路由真实任务
- 来源: https://thenextweb.com/news/google-cloud-next-ai-agents-agentic-era
- 日期: 2026-06-26
- 标签: #AI-Agent #A2A #MCP #企业落地 #协议生态

## 摘要
Google Cloud Next 2026 披露，Agent2Agent（A2A）协议从发布时 50+ 合作伙伴扩展到 150 家组织进入生产（非试点），在不同平台构建的 Agent 间路由真实任务；A2A 定位为补充而非取代 Anthropic MCP。同期 OpenAI Codex 企业版周活达 300 万，Anthropic 上线 Claude 企业工具市场（含 Snowflake 等伙伴）。

## 要点
- A2A 与 MCP 分层互补：A2A 管 Agent 间协作，MCP 管 Agent↔工具，两者并存成企业互操作事实基线
- 三巨头企业 Agent 路线分化：Google(A2A+Gemini 企业平台) / OpenAI(Codex+集成商) / Anthropic(Claude 企业市场)
