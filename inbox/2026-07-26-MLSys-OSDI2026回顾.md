# MLSys 2026 三大趋势 & OSDI'26 回顾
- 来源: https://www.modular.com/blog/three-trends-from-mlsys-2026
- 日期: 2026-07-26
- 标签: #MLSys #OSDI #系统顶会 #LLM推理 #AI-Agent

## 摘要
MLSys 2026（5月，Bellevue）LLM serving 从去年 3 个 session 扩至 6 个，成为绝对主角。AI Agent 写 kernel/系统代码成为新趋势。OSDI'26（7月，Seattle）新增 Operational Systems track，μShell 获 Distinguished Artifact Award。

## 要点
- **Agent 写系统代码**：Mark Saroufim 展示 AI agent 写 kernel 可接近 hackathon 头部水平；Lidong Zhou 主题演讲呼吁系统社区准备迎接 AI 作为底层代码主要作者
- **LLM 推理论文井喷**：SHIP（SRAM-based 推理管线）、PRISM（投机解码 draft model）、FlashAgents（多 agent 流式 prefill 重叠）、SuperInfer（superchip 调度）
- **Agent 基础设施**：OpenHands SDK 亮相，Hippocampus（agent 记忆模块）、AgenticCache（具身 agent 异步规划）
- **OSDI'26**：μShell 将微内核思想引入 FPGA 加速，实现硬件模块动态组合与 IPC；新增 Operational Systems track，接受率目标 ≥20%
