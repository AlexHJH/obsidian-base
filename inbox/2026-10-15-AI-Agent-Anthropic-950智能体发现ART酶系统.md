# Anthropic：950 个 Claude Agent 21 小时发现新酶系统 ART
- 来源: https://www.anthropic.com/news/claude-discovers-novel-enzyme-system ; https://www.techrepublic.com/article/news-anthropic-claude-ai-agents-enzyme-discovery
- 日期: 2026-10-12
- 标签: #AIAgent #多智能体 #科研自动化

## 摘要
Anthropic 2026 年春季组建生物学研究组，只给初始 prompt 就让 Claude Agent 群搜索 DNA 数据库里的反向转录酶；约 950 个 Agent 连续工作 21 小时、消耗约 2.1 亿 token，发现了一个此前未被描述的系统，命名 ART（array-associated reverse transcriptases）。

## 要点
- 过程像人类研究：某个 Agent 注意到某个异常 RT 基因旁有重复 DNA 序列并识别为 CRISPR 样串联重复阵列，随后自行计数、比对已知系统、查文献并产出报告；人类只负责初始提问与实验室验证
- 任务规模：筛过 20 万余个反向转录酶；ART 的重复结构与 CRISPR 有相似处，但功能未知
- 意义：这是「AI 提出假设 → 人类实验验证」闭环的一个公开样本，卖点是并行 Agent 的广度覆盖而非单一模型能力
- 口径提醒：官方博客与媒体报道均未给出对照基线（人类团队同样时间的产出），「发现」的独立价值需同行评议确认
