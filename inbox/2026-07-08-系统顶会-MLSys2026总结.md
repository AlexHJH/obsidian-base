# MLSys 2026: Best Paper LEANN 与三大趋势
- 来源: https://www.modular.com/blog/three-trends-from-mlsys-2026
- 日期: 2026-07-08
- 标签: #MLSys #系统顶会 #LLM推理 #Agent #稀疏计算

## 摘要
MLSys 2026 (Bellevue, 5/18-22) 落幕。Best Paper 授予 LEANN（低存储开销向量索引，设备端 RAG，97% 存储压缩）。Modular 总结三大趋势：AI Agent 开始写系统代码、LLM serving 爆发（6 session，翻倍）、稀疏计算成推理标配。

## 要点
- **Best Paper: LEANN** — UC Berkeley/Stanford 等团队的设备端向量索引，97% 存储压缩，推动端侧 RAG
- **Trend 1: Agent 写系统代码** — 新手用 AI Agent 写出接近 hackathon 顶级的 kernel；Lidong Zhou 主题演讲呼吁系统社区为 Agent 作为底层代码主要作者做准备
- **Trend 2: LLM Serving 主战场** — FlashAgents、Cascade (MoE 投机解码)、HiSpec (层次化投机解码)、LMCache (企业级 KV Cache)
- **Trend 3: 稀疏计算普及** — 非结构化稀疏、动态稀疏注意力 (MTraining) 用于超长上下文训练和推理
