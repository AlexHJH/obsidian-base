# Triton 3.8.0 发布：首支持 Rubin(SM107)，Gluon 拿到 CLC 与 TMA im2col
- 来源: https://github.com/triton-lang/triton/releases/tag/v3.8.0
- 日期: 2026-08-28
- 标签: #AI编译器 #Triton #Gluon #Rubin #MLIR

## 摘要
Triton 3.8.0（8/28）把 NVIDIA Rubin（SM107）拉进后端，补齐 Gluon 的显式控制能力（CLC 动态派活、TMA im2col、目标专用 API），并首次成体系引入编译期 sanitizer（FpSan/GSan/ConSan），代价是一批 IR 层 breaking change。

## 要点
- **Rubin 后端**：新增 SM107 初始支持（MMA 更新、multicast barrier arrival、Rubin 专用 Gluon module），并加四通道打包算术 `add4/sub4/mul4/fma4`（FP8/FP4）
- **Gluon 显式层**：Blackwell Gluon kernel 可用 Cluster Launch Control（CLC）做持久化 kernel 内的动态工作分配；新增 TMA im2col（含卷积教程）、3D dot FMA、SMEM atomic add、TMA atomics；`GenericLinearEncodingAttr` 支持 swizzle 与非单射布局
- **多 CTA 泛化**：multi-CTA 扩展到 layout conversion、reduction、local gather/scatter、TMA gather/scatter 与 multicast，配套 barrier 插入与内存分析更新
- **编译期 sanitizer**：FpSan 检查 kernel 变体是否保持同一符号浮点计算（覆盖 NVIDIA 与 AMD gfx942/950/1250、dot/WGMMA/MMAv5，新增 `tl.expect_zero`）；GSan 检测 GSan 分配器管理内存的数据竞争；ConSan 增 AMD 支持与 CLC/barrier 重初始化检查；FpSan/ConSan 改用驱动默认全局 scratch 分配器
- **内核/精度**：新增 NVFP4×NVFP4、MXFP4×MXFP4 输入组合、tensor-valued scale、Blackwell FP64 matmul 与 8x8x4 FP64 MMAv2 tile；`triton_kernels` 加 FP64 matmul 路径
- **扩展机制**：out-of-tree 扩展可定义自定义 Python DSL op、扩展 AxisInfo 分析、向注册 pass 传字符串参数、检查插件版本——第三方硬件接 Triton 的门槛进一步降低
- **AMD 侧**：gfx1250/CDNA5 扩 TDM 软件流水、descriptor gather/scatter、分区 SMEM 布局与 warp pipelining；Gluon 暴露 `cdna5` 别名；新增 gfx906（GCN 5.1）目标
- **Breaking changes**：block pointer 迁到 Python 前端、IR 里的 `tt.make_tensor_ptr`/`tt.advance` 被删除；tensor descriptor 类型改为自带 shape/dtype/#layout；`tl.dot` 在非 FP32 累加器且未给 `out_dtype` 时默认输出累加器类型；Gluon packed 算术以 `add2/sub2/mul2/fma2` 取代 `blackwell.float2`
