# OWASP 发布 Agentic Applications Top 10：AI Agent 安全进入标准化阶段
- 来源: https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026
- 日期: 2026-08-19
- 标签: #AI-Agent #安全 #MCP #OWASP

## 摘要
OWASP GenAI 安全项目发布《Top 10 for Agentic Applications 2026》（ASI01–ASI10），经 100+ 专家评审，首次为自主 Agent 的十大安全风险建立标准化框架，覆盖目标劫持、供应链、记忆投毒等新攻击面。

## 要点
- 核心风险：目标劫持(ASI01)、Agentic 供应链漏洞(ASI04)、RAG 数据投毒(ASI06)、工具滥用、记忆投毒、失控 Agent
- MCP 成最大攻击面：MCPoison(CVE-2025-54136)、CurXecute、MCP Inspector RCE，60 天 30+ CVE；82% 实现存在路径穿越、仅 8.5% 用 OAuth
- 落地缺口：Cisco 2026 调研 83% 企业已部署 Agent，仅 29% 自认具备足够防护；Tenet「agentjacking」2388 家机构可注入、85% 执行率
- 配套生态：Invariant Labs mcp-scan 扫描器、OWASP MCP Top 10、CoSAI MCP Gateway 零信任网关
