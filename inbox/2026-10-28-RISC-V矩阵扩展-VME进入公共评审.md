# RISC-V VME（Zvopmm）进入公共评审，11 月走 TSC/BoD 批准
- 来源: https://riscv.atlassian.net/wiki/spaces/VMEX/pages/663617995/Ratification+Plan
- 日期: 2026-10-09
- 标签: #RISC-V #VME #矩阵扩展 #标准进展

## 摘要
VME TG 的批准计划表把 Zvopmm 推到 Public Review（10-09 启动），后续 TSC 批准 11-04、BoD 批准 11-18。若按期，VME 会成为三种矩阵方案里第一个走到 ratified 的，比仍在 ARC 后的 IME 快一个身位。

## 要点
- 里程碑链：Plan Approval 07-16 → Internal Review 07-30 → ARC Freeze Request 08-20 → (09-25) → Public Review 10-09 → TSC 11-04 → BoD 11-18
- 规格名是 **Zvopmm**，Jira RVS-3923，状态 Freeze —— 与 IME 的 Zvvm family 命名体系不同，引用时别混
- 语义定义：两条向量寄存器的外积累加进一个大矩阵累加器（两个 N 元向量寄存器做 N² 次 MAC）
- 口径注意：这是**计划表**，不是 ratified 事实；表中日期属 forecast，需以 spec dashboard/release tag 复核
