# A2A 并入 AAIF：Agent 协议战争落幕
- 来源: https://forkast.news/googles-a2a-protocol-joins-aaif-consolidating-the-agent-economys-protocol-layer-under-one-roof
- 日期: 2026-09-06
- 标签: #AI-Agent #A2A #MCP #协议标准

## 摘要
Google 于 8/20 把 Agent2Agent (A2A) 协议正式移交 Linux Foundation 旗下的 Agentic AI Foundation (AAIF)，与 Anthropic 的 MCP 归入同一中立治理，两大开放 Agent 标准首次统一。

## 要点
- MCP 管「agent↔工具」垂直集成，A2A 管「agent↔agent」水平通信，分工互补
- 8 家白金赞助：AWS/Anthropic/Block/Bloomberg/Cloudflare/Google/Microsoft/OpenAI；成员从 3 月 49 家增至 250+
- 第三层 WebMCP 正在成型，MCP+A2A+WebMCP 三层协议栈成共识
