# 华为 openJiuwen + 昇腾「算力亲和」：Agent 推理首 Token 时延砍半

## 摘要
华为 2012 实验室、云、计算、终端联合打造的开源智能体平台 openJiuwen 联合昇腾推出「算力亲和」全链路协同技术：以 Agent Hint「状态契约」打通 Agent 框架与推理引擎语义通道，让 KV Cache 随任务节奏主动流转。

## 要点
- 首 Token 时延降 57%+、推理存储峰值降 25%；实测端到端时延 -27.61%、前缀缓存命中率 +33%
- 缓存不再只有「留在显存/排队淘汰」两种命运，而是按驱逐/卸载/预取在存储层级间主动流动；能力即将开源
