- 日期: 2026-10-05

## 摘要
v0.31.0 于 10/5 发布，717 commits / 307 贡献者（96 新）。主线仍是 DeepSeek-V4.1-Flash 的 kernel 融合（FlashMLA mega attention + NVFP4 压缩 KV cache 成 SM100 默认；Mega-Gate 融合门控 GEMM 与专家选择；decoder 边界融掉 TP all-reduce 与 MoE finalize）与大规模并行（MoonEP 均衡 EP all2all、DeepEPv2 + 序列并行、EPLB 共享专家重叠）。但结构信号在「重启成本、卸载背压、准入控制」三处。

## 要点
- 快重启：`vllm preload` 启权重缓存守护进程，把已量化权重常驻显存跨引擎重启复用（支持 DP、MTP draft、`/health`、就绪等待）；实验性 `vllm snapshot create/restore` 用 CRIU 恢复已初始化的 TP1 引擎
- 大规模服务：KV offloading 新增背压检测（#50045）；prefill context parallelism 与 DP 组合；新增 `--all2all-backend moonep`
- 调度：`--max-num-active-seqs` 把 RUNNING 准入与 `max_num_seqs` 解耦；`--long-prefill-token-threshold` 改为按等待 prefill 数量自适应（不再只 chunk 单个请求）；等待队列重做，已持有 KV 块的请求优先调度；修掉 KV connector + MTP 在 KV 压力下的死锁
- 安全/兼容：per-request 多模态 kwargs 默认拒绝（需 `--trust-request-mm-kwargs`）；prefix-cache extra key 按来源打标签（LoRA 名与 `cache_salt` 不再相撞）、LoRA 路径进 block hash；`tokenizer_mode="slow"` 移除、`--enforce-eager` 同时禁用 JIT warmup、XPU graphs 默认开启
- 读法：与 [[推理引擎格局-vLLM-SGLang]] 的 v0.30 Fast Start / 分层 KV 卸载同线 —— 引擎优化对象从稳态吞吐扩到「重启、卸载与队列准入」这些运维面
