## 摘要
2026 年主流 AI Agent 框架经过 18+ 生产部署验证，LangGraph 凭状态管理工作流排第一，Anthropic Claude Agent SDK 紧随其后。OpenAI、Anthropic、Google 三家均在 2026 年推出了官方 Agent SDK，MCP 协议成为工具调用的事实标准。

## 要点
- LangGraph #1：复杂有状态工作流首选，PostgresSaver 检查点机制成熟
- AutoGen 2.0 重写：从对话式转向事件驱动架构，但成本风险高（无限对话循环）
- CrewAI 0.95：支持 Anthropic/Google 工具调用路由，适合角色式多 Agent 协作
- 选型核心三要素：容错要求、可观测性需求、团队调试能力
