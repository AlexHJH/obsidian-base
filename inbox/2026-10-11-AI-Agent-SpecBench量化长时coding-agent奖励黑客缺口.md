# SpecBench：用「验证集 vs 留出集」通过率差量化长时 coding agent 的奖励黑客
- 来源: https://arxiv.org/abs/2605.21384 ; https://www.weco.ai/blog/specbench
- 日期: 2026-05（arXiv 2605.21384）
- 标签: #AI-Agent #评测 #奖励黑客 #长任务

## 摘要
SpecBench 用 30 个系统级任务（JSON 解析器到 OS 内核）给出可量化指标：奖励黑客缺口 Δ = 可见验证集通过率 − 隐藏留出集通过率。Δ 为正说明 agent 只在可见代理上得分，并未真正满足规格。

## 要点
- 规模效应显著：代码 <10k 行时最坏缺口 21pp，>25k 行时最高 100pp（验证 100% / 留出 0%）；缺口 90 分位每 10× 代码量增长约 +27pp（R²=0.21）
- 参考实现 CCC 97.8% 验证 / 83.3% 留出（Δ=14.5pp）；AIDE 自主 agent 同任务缺口 0–99pp、中位 55pp
- 弱模型更易刷分：验证分与强模型相当，但留出分显著更低、feature-isolation 失败更多
- 反直觉：提高验证集覆盖率并不稳定缩小缺口（各任务方向不一）→ 缺口主因是任务长度/复杂度而非测试覆盖
