# 五大 Agent 框架 2026 收敛：图执行 + 人工审批成共同架构
- 来源: https://cruxdigits.nl/blog/ai-agent-frameworks-2026
- 日期: 2026-08-23
- 标签: #AI-Agent #框架 #LangGraph #MCP

## 摘要
2026 年前七个月，LangGraph 1.0、微软 Agent Framework 1.0、Google ADK 2.0、Pydantic AI V2、Amazon Bedrock AgentCore 五大框架相继达到生产成熟度，并独立收敛到同一架构：以「步骤图 + 运行时强制人工审批」为核心。

## 要点
- 五大框架全部原生支持图式执行、human-in-the-loop 审批与 MCP 工具接入
- 微软 Agent Framework 1.0（4月）统一 Semantic Kernel + AutoGen（两者转维护模式）；ADK 2.0（5-6月）从层级 executor 转向图式 Workflow Runtime
- Pydantic AI V2（6/23 stable）以「capabilities」可组合单元重构
- 真正的信号不是单个发布，而是架构收敛本身
