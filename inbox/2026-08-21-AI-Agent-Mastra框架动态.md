## 摘要
Mastra 是 Gatsby 团队打造的 TypeScript 优先 Agent 框架，2026 年 1 月发布 1.0，完成 $13M 种子轮与 $22M A 轮，转 Apache 2.0 许可，月下载量超百万。

## 要点
- 8 月连发：AI SDK v7 支持、内置工具、Coding Agent Helper、细粒度鉴权
- 从框架向平台演进（Mastra Factory、Agent Builder、Observability）
- 记忆网关 Memory Gateway 提供即插即用的持久记忆端点
