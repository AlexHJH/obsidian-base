# Anthropic 9 月威胁情报报告：agentic 攻击框架已扩散到每一类行为体

- 来源: https://www.anthropic.com/threat-intelligence-report-september-2026 ; https://blog.7ai.com/anthropics-threat-report-details-on-ai-driven-attack
- 日期: 2026-09-10
- 标签: #AIAgent #安全 #威胁情报 #多智能体 #misuse

## 摘要
Anthropic 发布第 4 份威胁情报报告（154 页），覆盖 2025-12 至 2026-08 被中断的滥用行动。核心结论：去年只有疑似国家级行为体会用的「自主攻击运营模式」，如今在国家级、犯罪团伙、单独黑客三类行为体上全部复现；公开的攻击型 agent 框架（如 PentAGI）把这些脚手架民主化了，区分行为体的不再是技术水平，而是意图。

## 要点
- 自主度光谱：从把模型当工程助手（写恶意代码）→ 人类逐步决策指挥执行（GTG-20006）→ 多 agent 框架自主对多个受害者并行侦察/利用/窃取数小时到数天（GTG-50014 / 50020 / 50029），以及完全无人在环的定时采集集群（GTG-10007）
- GTG-20006（与 Midnight Blizzard 公开报道一致）：AI 工作流自动化从开发、基础设施采购、钓鱼、持久化到外泄全过程；**检测对抗自动化**——监控 agent 发现恶意软件被查杀就去自主改写重建，循环到不被检测
- GTG-50029（单一法语黑客，无国家背景）：用 agentic 编码框架管理子 agent，子 agent 分工做认证前后侦察、代码审查与多模型结论互校；现场开发 WordPress 竞态漏洞利用、webshell 藏在字体资源并污染备份做持久化
- 佐证规模化的两个数字：一条凭据收割流水线批量下载并反编译 180 万款 Android APK 扫硬编码密钥；某约会应用网络两周内 4,700+ AI 人格与至少 2.5 万名真人对话（AI:真人 ≈ 3:1）
- 判断：AI 没有发明新攻击，只是让老攻击变便宜；防御侧需要的是「独立于提交者的验证」——与 [[MLSys2026论文精选]] 的 zero trust keynote 同构
