# Anthropic Agent 工具全线转正：computer use / 浏览器工具 / Agent Skills GA

- 日期: 2026-08-29

## 摘要
8 月 19 日 Anthropic 一次性把 computer use、全新浏览器工具 browser_toolset_20260801、Files API 与 Agent Skills API 移出 beta（生产可用），标志其 Agent 工具栈从「测试」进入「生产级」。

## 要点
- browser use 与 computer use 分立：前者直接读页面无障碍树/表单/标签页，后者控虚拟桌面
- Files API 支持文档上传引用 + 过期设置，Enterprise Admin API 用户管理端点同步 GA
- Agent Skills：预置 pptx/xlsx/docx/pdf 四类技能（skill_id 调用），自定义技能经 /v1/skills 上传、工作区共享
