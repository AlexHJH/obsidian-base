# MLX 接入 M5 神经加速器：Apple 官方基准
- 来源: https://machinelearning.apple.com/research/exploring-llms-mlx-m5
- 日期: 2026-06-19
- 标签: #MLX #AppleSilicon #M5 #推理优化

## 摘要
Apple ML 研究团队宣布 MLX 已在最新 macOS beta 中启用对 M5 芯片「神经加速器（Neural Accelerators）」的支持。神经加速器提供专用矩阵乘法单元，可显著加速 LLM 推理中的密集线性代数运算。

## 要点
- 神经加速器位于 M5 GPU 内，专职矩阵乘法（GEMM），是 LLM 推理的核心算子
- 官方在 24GB M5 MacBook Pro 上对不同规模/架构的 LLM 做基准，与同配置 M4 对比
- MLX 覆盖全部 Apple Silicon，定位「本地私密推理 + 研究实验」的首选框架
- 趋势：硬件（M5 专用加速单元）+ 软件（MLX）协同推进端侧大模型推理性能
