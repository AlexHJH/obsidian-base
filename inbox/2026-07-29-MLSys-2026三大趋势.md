# MLSys 2026 三大趋势：Agent 写 Kernel、异构推理、KV Cache 外移
- 来源: https://www.modular.com/blog/three-trends-from-mlsys-2026
- 日期: 2026-07-29
- 标签: #MLSys #LLM-serving #KV-Cache #异构计算 #Agent

## 摘要
MLSys 2026 LLM Serving 专场翻倍至 6 个 session。三大趋势：(1) Agent 写系统代码成为现实，Lidong Zhou 呼吁社区为 Agent 作为代码主要作者做准备；(2) 异构硬件成推理标配，从 GPU 到专用 NPU/MPU 混合部署；(3) KV Cache 从 GPU 显存外移到 DRAM/SSD/分布式存储，Netpreme 甚至推出专用 Memory Processing Unit。

## 要点
- LLM Serving 6 个 session + 2 个 Industry Track，比去年翻倍
- Agent 已能写出接近 hackathon 顶级的 kernel 代码（KernelPro 等）
- KV Cache 管理成推理系统第一痛点：placement/transfer/eviction/reuse 策略跨多层存储
- Netpreme MPU 宣称将 XPU 内存扩展 100×
- 竞赛 Track：Trainium2/3 MoE Kernel、Google Graph Scheduling、NVIDIA FlashInfer AI Kernel Generation
