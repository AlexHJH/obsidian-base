# 首个 HBF 用于 LLM 推理的系统研究：容量换带宽，读带宽与寿命是前提
- 来源: https://arxiv.org/abs/2608.13868
- 日期: 2026-09-05
- 标签: #HBF #AI推理内存 #LLM推理 #论文

## 摘要
arXiv 2608.13868 首次系统研究 HBF 在现代 LLM serving 中替代 HBM 的机会与挑战：可显著提升 batch size/吞吐/灵活性并降低最低 GPU 门槛，但前提是读带宽逼近 HBM、写入性能与寿命大幅改善。

## 要点
- HBF 容量优势显著，但作为 GPU 主存时写性能与 endurance 是主要制约，需「HBM 级读带宽」才能兑现收益
- 结论与 OXMIQ 互为补充：HBF 有价值但非普适替代，落地依赖软硬协同改造
