# Anthropic 发布 Model Hardware Standard：让 Agent 控制物理硬件
- 来源: https://www.computerworld.com/article/4215388/anthropics-new-framework-lets-ai-agents-control-hardware.html
- 日期: 2026-08-28
- 标签: #AIAgent #Anthropic #硬件控制 #具身智能

## 摘要
Anthropic 推出 Model Hardware Standard（MHS），一套标准化驱动，让 AI agent 直接操作物理硬件——机器人、显微镜，甚至量子计算机的激光标定。官方计划经充分测试后开源。

## 要点
- 定位不是编排框架，而是「模型 ↔ 硬件」的接口标准：把设备能力抽象成模型可安全调用的统一驱动面
- 首批目标场景是实验自动化（新药研发、量子计算标定）而非消费级机器人
- 战略含义：前沿实验室开始抢占 agent 的物理执行层标准，与 MCP 之于工具层是同一套逻辑
- 待观察：授权与安全边界（谁能允许 agent 动硬件）、开源时间表、是否有硬件厂商跟进采纳
