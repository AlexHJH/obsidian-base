# Apache TVM 发布 TIRx：面向前沿 ML kernel 的硬件原生 DSL/编译器
- 来源: https://tvm.apache.org/2026/06/22/tirx
- 日期: 2026-06-22
- 标签: #AI编译器 #TVM #TIRx #kernel-DSL #Blackwell

## 摘要
Apache TVM 发布 TIRx——开源硬件原生 kernel DSL 与编译器，定位"快速演进的 kernel × 快速演进的硬件"交汇地带，现可编译到 GPU 与专用 AI 加速器。同一套设计同时服务手写 kernel、Agent 生成 kernel 与 megakernel 系统。

## 要点
- Python 内嵌 DSL：`@T.jit` / `@T.prim_func` 风格编写，核库含 GEMM/attention/低精度算子（Blackwell）
- 设计借鉴 NumPy/CuTe/Triton/ThunderKittens/TileLang；集成 FlashInfer、FlashAttention sm100（CuTeDSL）、cuBLASLt NVFP4 参考实现
