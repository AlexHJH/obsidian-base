# Triton 跨厂商基准测试 + 内核指针安全性形式化验证
- 来源: https://next.redhat.com/2026/02/12/from-hand-tuned-to-generated-a-reproducible-triton-gpu-kernel-benchmark-across-different-vendors
- 日期: 2026-06-19
- 标签: #AI编译器 #Triton #GPU #基准测试 #形式化验证 #MLIR

## 摘要
两篇新工作推动 Triton 从"能用"走向"可信"：Red Hat 发布跨厂商可复现 Triton GPU kernel 基准，对比手写专家调优 vs 自动生成；社区提出用 Z3 SMT 求解器对 Triton 内核做指针安全性的形式化证明，向编译器集成征集方案。

## 要点
- Red Hat 基准：四种路线横评（手写 Triton / 自动生成 / 各厂商后端），强调可复现性与跨 vendor 可移植性
- Triton 2.0 后端已重写为 MLIR，手写与自动生成 kernel 的性能差距持续缩小
- 指针安全验证器：基于 Z3 SMT 静态证明内核无越界访问，瞄准集成进 Triton 编译流水线
- 趋势：AI 编译器竞争从"覆盖更多硬件"转向"生成代码更优 + 正确性可证明"
