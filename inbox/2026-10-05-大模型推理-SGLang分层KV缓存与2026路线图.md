## 摘要
SGLang 的技术叙事正从前缀复用扩到「分层 KV 缓存 + 混合注意力内存池」：GOSIM Shenzhen 2026（10/17）专设工作坊讲这套栈——RadixAttention / Unified RadixAttention、HiCache 跨存储层级搬 cache、以及面向混合注意力模型的 Unified Memory Pool。2026 Q2 路线图把「分层缓存与混合注意力原生化」「为 agentic 负载提供弹性 session 控制」列为主目标。

## 要点
- KV cache 管理从「省重算」升级为「跨层存储 + 会话态」：HiCache 在层级间搬 cache，Unified Hybrid Radix Cache 重构（#20415）把混合注意力收进同一棵树
- 面向 agentic：Distributed KVCache System for Agentic Workload（#21846）+ session-aware 管理，让多轮重复前缀不再重复 prefill
- 长上下文走稀疏：HiSparse 路线图（#28874）针对长上下文稀疏 serving；另有 elasticmem 集成
- 调度侧同期重构：forward-mode 泛化、scheduler 更无状态、完全支持 mixed chunked prefill、把准备逻辑更多挪进 CUDA graph 以降 CPU 开销
- 生产侧佐证：LMCache 的「多进程 KV cache」与 KV 持久化到 S3（NIXL / ICMS / Mooncake 一线）已成 2026 独立赛道
