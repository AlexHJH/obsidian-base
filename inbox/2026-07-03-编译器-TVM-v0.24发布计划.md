# Apache TVM v0.24.0 发布在即：社区启动 release schedule
- 来源: https://github.com/apache/tvm/issues/18921
- 日期: 2026-07-03
- 标签: #AI编译器 #TVM #v0.24 #Relax #TensorIR

## 摘要
Apache TVM 社区启动 v0.24.0 发布流程，距 v0.23.0（2026年2月）约 5 个月，预计近期正式发布。主分支已合并 Unity (Relax + TensorIR) 为默认编译流程，新版本将首次以 LLM 编译为一级场景。

## 要点
- v0.23.0 于 2 月发布，v0.24.0 是 Unity 并入后的首个正式版本
- 核心变化：Relax（高层图IR）+ TensorIR（Tensor级IR）统一为 Graph-TIR 范式
- MLC LLM 已基于 Unity 实现浏览器/手机/GPU 跨平台 LLM 部署
