# Helion 1.0：PyTorch Foundation 托管的高层 kernel DSL，向后端扩到 TPU
- 来源: https://pytorch.org/blog/helion
- 日期: 2026-04-07（1.0 GA / 基金会托管；TPU 后端为 2026-08）
- 标签: #AI编译器 #Helion #PyTorch #DSL #AutoTuning

## 摘要
Meta 贡献的 Helion 在 PyTorch Conference Europe（巴黎，4/7）发布 1.0 并成为 PyTorch Foundation 托管项目，与 DeepSpeed、PyTorch、Ray、vLLM 并列。它把 kernel 写作抬到比 Triton 更高一层：开发者只写 tile 级高层描述，编译器自动生成并基准测试大量 Triton 变体，自动探索 num_warps/num_stages/range_unroll_factors/range_warp_specializes 等调优参数。

## 要点
- 性能口径（PyTorch 官方）：平均比 torch.compile 快 1.05×、比手写 Triton kernel 快 1.44×；AMD MI350X 上相对 eager 2.37×（torch.compile 2.26×、Triton 1.65×），int4_gemm/jsd 比手写 Triton 快 4.5×/4.4×，Mamba2 chunk scan 上超过 TileLang
- 与 Gluon/CuTe-DSL/TileLang/TLX 的分工：Helion 走「高层 + 自动调优」，Gluon/TLX 走「显式控制换性能上限」；两者都编译到同一 Triton 栈
- 与 autoWS 通吃：Triton 的自动 warp specialization 对 Triton 手写、TorchInductor 与 Helion 生成的 kernel 通用（见 [[inbox/2026-09-17-AI编译器-Triton-autoWS设计与路线图]]）
- 生态扩张：与 TorchTPU 协作落地 Helion for TPU（2026-08 披露），宣称换成该 API 后工作负载自动吸收后续编译器/硬件优化，无需重写
