# MLSys 2026 三大趋势：从系统优化到系统智能
- 来源: https://www.modular.com/blog/three-trends-from-mlsys-2026
- 日期: 2026-07-13
- 标签: #MLSys #系统顶会 #LLM推理 #AI Agent

## 摘要
MLSys 2026（5月西雅图）揭示三大趋势：LLM 推理专场翻倍（6 场 vs 去年 3 场）、AI Agent 开始编写内核/系统代码、系统社区需为「AI 作为系统作者」做好准备。

## 要点
- **Best Paper: LEANN** — 低存储开销向量索引，由 Berkeley/CMU 联合团队提出
- **LLM Serving 爆炸**: 6 个专场，覆盖从调度到 KV-cache 管理的全栈优化
- **Agent 写 Kernel**: Mark Saroufim 展示新手用 AI Agent 写 GPU kernel 可达黑客松前列水平
- Lidong Zhou 主题演讲：「从 MLSys 到 System Intelligence」，系统社区需拥抱 AI 作为代码作者
