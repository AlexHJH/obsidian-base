# Agent 运行时安全：零点击插件 RCE、首例 agent 致数据泄露申报、Safari 27 本地 MCP
- 来源: https://aiagentstore.ai/ai-agent-news/this-week
- 日期: 2026-09-20
- 标签: #AIAgent #安全 #治理 #MCP

## 摘要
9/20 周报汇总三条改变威胁模型的事件：影响主流 coding agent 的 Plugin4Shell 零点击插件 RCE、首例由 LLM agent 触发并正式申报的数据泄露（西班牙 AEPD）、Safari 27 内置本地 MCP server 把浏览器自动化开放给 MCP agent。

## 要点
- 插件供应链：Plugin4Shell 零点击 RCE 波及主流 coding agent → 必须校验插件签名与更新策略，配 per-agent 最小权限凭据
- 合规已成事实：监管机构受理了「agent 引发数据泄露」的正式申报，agent 事故进入法律与审计流程，不再只是工程问题
- 新攻击面：Safari 27 的本地 MCP server 扩大了 agent 可作用面，需写进威胁模型与审计清单
- 治理产品成波：Alation AIOS 增加 agent 合规实时监控与血缘追踪；Exaforce / Eve Security / Cohesity（Agent Resilience 支持回滚）/ Arcjet 提供 kill switch 与运行时管控
- 可量化 KPI：Anthropic 披露内部常驻约 3 万 agent、8 月 10 亿次决策中约 0.002% 被实时监控拦截（约 2 万次干预）→「干预率」开始与 uptime、错误预算并列
