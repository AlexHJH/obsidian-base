# mlx-lm 九月迭代：补 Mistral4 / Spark-X2.5，社区当天上架多模态量化模型

- 来源: https://github.com/ml-explore/mlx-lm/commits/main ; https://github.com/ml-explore/mlx/commits/main ; https://huggingface.co/models?author=mlx-community
- 日期: 2026-09-22
- 标签: #MLX #模型支持 #推理引擎

## 摘要
9 月 mlx-lm 提交密集：新增 Mistral4、Spark-X2.5 原生支持，Qwen2 / Qwen3-Next 支持 `pipeline()`，并修复 Nemotron-H、MLA 混合位量化、工具调用解析等一批问题。mlx 核心同期在 Metal 侧补上 gated delta net 内核、量化 matmul 的 global scale 与 D512 vector attention。社区侧 mlx-community 当天就上传了 Qwopus3.8-27B-Flash-V2（bf16/8bit/6bit/4bit）等新模型的 MLX 版本。

## 要点
- 发布节奏：main 分支持续推进，最新 release 仍分别是 mlx v0.32.2（2026-08-25）、mlx-lm v0.31.3（2026-04-22），功能靠 main 落地
- mlx-lm 新增：Mistral4 (#1012)、Spark-X2.5 (#1891)、OLMo Hybrid 转换技能 (#1023)、laguna 公开权重 (#1704)
- 修复类：部分上下文截断后 continuation 打分 (#1902)、Gemma3n offset 预计算 (#1886)、MLA 混合位量化加载 (#1482)、Qwen3 nested rope_parameters (#1898)
- mlx 核心 Metal：gated delta net 内核 (#4020)、qmm global scale (#4458)、D512 vector attention (#4459)、拷贝时释放 GIL (#4497)
- 社区当日上架：Qwopus3.8-27B-Flash-V2（image-text-to-text MoE）、MiMo-V2.6-Flash-RL-mxfp4-q8
