# TVM v0.25.0 发布：TIR 重构与 Relax 增强
- 来源: https://github.com/apache/tvm/releases/tag/v0.25.0
- 日期: 2026-07-21
- 标签: #AI编译器 #TVM #TIR #Relax #MLIR

## 摘要
Apache TVM 发布 v0.25.0，重点是 TIR 层重构（淘汰 ControlFlowGraph、NarrowPredicateExpression）和 Relax 前端的 CUDA/ONNX/Torch 兼容性修复。Analyzer 重构为 tvm-ffi Object，TIRx 方向持续演进。

## 要点
- TIR 重构：移除 ControlFlowGraph 和 NarrowPredicateExpression，Simplify 重命名 StmtSimplify
- Relax 修复：scatter_elements/scatter_nd CUDA 编译、ONNX/Torch 多输入转换
- Analyzer 升级为 tvm-ffi Object，TIRx 测试适配新版 TIR API
