# HBFSim：在真 GPU 上忠实模拟 HBF 的容量/放置决策（arXiv 2609.09800）
- 来源: https://arxiv.org/abs/2609.09800
- 日期: 2026-09-19
- 标签: #HBF #AI芯片 #LLM推理 #模拟器 #NAND

## 摘要
HBF 规格 2026-08-03 已发布、首批器件 2027 年初才出样，容量与数据放置决策却等不起硅。HBFSim 改写 PTX 并 gate kernel launch，把 HBF 的时序/容量/热效应注入真实 GPU 上运行的真实推理负载，是首个「真机 + 真负载」的 HBF 评估平台。

## 要点
- 既有手段都不够：存储模拟器只回放访问序列不跑负载；GPU 模拟器不执行真实 kernel；周期精确模拟器跑不完一次推理
- 机制：发射（issue）与消费分离，让真硬件执行的计算去隐藏 HBF 访问延迟；时序取自真机测量而非参数表
- 热与保持：结温同时决定 HBF 可持续带宽与保持期限（到期强制 refresh 写），把 NAND 温变特性纳入评估
- 结果：6 个校准点与实测器件完全一致、零危险发射；未改动的 vLLM 0.15.1 服务 Qwen3-30B-A3B 输出 token 与基线一致；快路径 2s vs 详细参考路径 44s（20.8×）
- 意义：补上 H3 / FLINT / FlashAccel 一类 HBF 研究缺的公共评估底座，出样前即可度量容量与放置取舍
