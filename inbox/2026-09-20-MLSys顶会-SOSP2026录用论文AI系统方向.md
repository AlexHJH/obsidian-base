# SOSP 2026 录用论文公布：AI 系统与 LLM 服务成最大板块
- 来源: https://sigops.org/s/conferences/sosp/2026/accepted.html
- 日期: 2026-09-20
- 标签: #SOSP #系统顶会 #LLM推理 #AI系统

## 摘要
第 32 届 SOSP（9/29–10/2，布拉格）公布条件录用名单，AI 相关论文已成最大集群：LLM 推理与训练、GPU 内核/调度、Agent 文件系统、验证与形式化四个方向同时放量，会议本身首次移师中欧。

## 要点
- **训练/推理基础设施**：CrystalLLM（阿里 + Harvard/SJTU）用少量 GPU 做「忠实」的大规模 LLM 训练模拟；ACDC（SJTU + 阿里）刻画并优化生产环境离线推理（Batched in Back）；Janus（北大 + 京东）做生产级 multi-LLM serving；StreamEP（USC + SNU）实现无通信壁垒的抗拖尾 MoE 解码
- **确定性/可重复性**：LLM-42（MSR + UW）用 verified speculation 让 LLM 推理具备确定性；LMTracer（清华 + Rank Computing）做生产 LLM 系统的细粒度实时 profiling
- **GPU 内核与调度**：Taming Dynamism on GPUs（SJTU，陈海波组）用跨 SM kernel fusion + JIT reduction 治动态性；Anchor（清华）用解耦内存缓解 GPU shallow disruptions；Morphable Kernels（清华）做多任务形态可塑内核；M2K（PSU + 中科院）把 model-kernel 接口显式化以支持 CUDA 内核验证
- **Agent 与文件系统**：Don't Let AI Agents YOLO Your Files（UW-Madison，Arpaci-Dusseau 组）提出 agent-native 文件系统的信息与控制模型；AgileLog（UIUC）为数据流上的 Agent 做可 fork 共享日志
- **编译与 wafer-scale**：MeshRT（Edinburgh + MSR）做编译期治理的晶圆级低延迟运行时；Wavel（Edinburgh + MSR）是 wafer-scale 加速器的编译系统——晶圆级算力开始有自己的编译栈议题
- **异构/新内存**：StarfishOS（SJTU）在 CXL 上重审单系统镜像；XTRA（华科）统一 CXL pod 的缓存一致性与并发控制；Borges（UT Austin + Anthropic）做 CXL/SSD 混合上的低延迟分布式共享日志
- **验证主线**：Welder（UIUC + Wisconsin 等）做集群控制面的组合式活性验证；Sockeye（ETH Zurich）基于参考手册对平台配置与硬件做 bug-finding 与证明——形式化验证正从论文原型走向控制面与配置这类工程重灾区
