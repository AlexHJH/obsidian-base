# 华为发布 OceanStor M900 Context Memory Storage：PB 级 KV Cache 共享内存层

- 来源: https://www.huawei.com/en/news/2026/9/hc-context-memory-storage
- 日期: 2026-09-17
- 标签: #大模型推理 #KVCache #存算协同 #华为 #超节点

## 摘要
华为全联接 2026（9/17，上海）由轮值董事长 David Wang 发布 OceanStor M900 Context Memory Storage：为 SuperPoD 提供 PB 级、TB/s 级性能的全共享内存空间，在片上内存 / DRAM / SSD 之间对 KV Cache 做分层与调度。官方口径是 AI 基础设施从「算力为中心」转向算力、网络、存储深度协同。

## 要点
- 命名从「存储」变成「上下文内存」：把 KV Cache 当外部记忆层统一编址，而非把 SSD 当盘用
- 服务于 Agent 化负载：多轮、长链路会话让 KV 需求呈指数增长，显存容量增长跟不上上下文扩张
- 与昇腾 960 超节点的 L3.5 层 KV 缓存方案配套，灵衢一跳直连（见 [[AI芯片推理硬件2026全景]] 侧记录）
- 存储厂商各自下注同一战场（[[#KV Cache 卸载进入生产：ODCC 全场景测评的量化结论]]），差别在接口协议（灵衢 vs Spectrum-X/RDMA）与是否绕过 host
