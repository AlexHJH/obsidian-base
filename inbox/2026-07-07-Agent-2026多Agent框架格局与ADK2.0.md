## 摘要
2026 年中，多 Agent 框架生态进入成熟期。LangGraph 以月搜索量 27,100 领跑，CrewAI 紧随其后（14,800）。Google 在 I/O 2026 发布 ADK 2.0（支持 Python/TS/Go/Java），引入 Antigravity 编排面板和 Managed Agents 企业级部署能力，标志着框架从「能跑」到「生产可用」的跨越。

## 要点
- 六大主流框架：OpenAI Agents SDK、LangGraph、CrewAI、AutoGen/AG2（微软）、Google ADK、Claude Agent SDK（Anthropic）
- Google ADK 2.0 核心升级：代码优先多 Agent 编排 + SequentialAgent 工作流 + 树形 Agent 层级结构
- 协议层趋同：MCP（工具连接，9700 万下载）和 A2A（Agent 间通信，50+ 合作伙伴）成为事实标准
- 选型关键：LangGraph 适合复杂图工作流，CrewAI 上手最简单，ADK 适合 GCP 生态深度用户
- [[AI-Agent-2026格局]] 中 MCP/A2A 之争正在从协议竞争走向生态融合
