# vLLM Decode Context Parallelism：长上下文 KV Cache 按序列分片
- 来源: https://vllm.ai/blog/2026-08-07-decode-context-parallelism
- 日期: 2026-08-07
- 标签: #大模型推理 #vLLM #长上下文 #KV-Cache #上下文并行

## 摘要
vLLM 原生支持 Decode Context Parallelism（DCP）：把 KV Cache 沿序列维度分片到各 GPU，每卡只存 1/N，破解长上下文下张量并行按 attention head 切分导致的 KV 冗余复制与 GQA/MLA 瓶颈。

## 要点
- 相比标准 TP，长上下文 agent 负载吞吐最高提升 3×；8×B200 跑 Kimi K2.6 达 6,091 tok/s/GPU（并发 512、KV 利用率 82%）
- attention 后立即重配 GPU 摊薄 FFN 权重加载，随上下文长度优雅扩展而非退化
- NVIDIA TensorRT-LLM 同方向推 Helix（context+tensor）并行；下一步发布 Kimi K3 的 DCP 基准
