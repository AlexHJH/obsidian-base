# MLX 迎来 CUDA 后端：从 Apple Silicon 独占迈向跨平台
- 来源: https://tw.news.yahoo.com/%E8%98%8B%E6%9E%9C%E8%B7%A8%E5%B9%B3%E5%8F%B0%E6%9C%AC%E5%9C%B0-ai-%E6%99%82%E4%BB%A3%E4%BE%86%E8%87%A8-apple-ml-230859626.html
- 日期: 2026-09-04
- 标签: #MLX #Apple-Silicon #CUDA #跨平台

## 摘要
MLX 维护者 Cheng Zhao 宣布 CUDA 后端全部测试通过，标志着 Apple 的 ML 框架首次完整支持 NVIDIA 生态。`pip install "mlx[cuda]"` 即可启用，同一套 MLX 代码可在 MacBook 与 NVIDIA GPU 机器间无缝切换。

## 要点
- MLX 从「Apple Silicon 独占」跨出关键一步，CUDA 支持全量通过测试
- 生态认证背书：Ollama 2026 年 3 月已将 Apple Silicon 推理引擎切至 MLX
