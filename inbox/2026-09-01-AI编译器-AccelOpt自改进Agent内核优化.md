# AccelOpt：自改进 LLM Agent 做 AI 加速器内核优化 (MLSys'26)
- 来源: https://arxiv.org/abs/2511.15915
- 日期: 2026-09-01
- 标签: #AI编译器 #AI-Agent #Kernel优化 #MLSys

## 摘要
Stanford × AWS × Toronto 提出 AccelOpt，一个自改进 LLM Agent 系统，无需专家提供的硬件专属优化知识即可自主优化新兴 AI 加速器（AWS Trainium）内核。通过迭代生成 + 优化记忆（沉淀慢-快 kernel 对经验）探索优化空间。

## 要点
- 首个无需专家优化配方/硬件专属知识的开源内核优化 Agent
- 新增 NKIBench 基准（Trainium 内核），吞吐显著提升且成本更低
