# 2026 Q2 Agent 框架：史上最密集迭代季

## 摘要
2026 Q2（4-7月）是 Agent 框架史上最繁忙的季度：微软合并 AutoGen+Semantic Kernel 发布 Agent Framework 1.0 GA，Pydantic AI V2 与 LlamaIndex Workflows 1.0 在 48 小时内先后 stable，Claude Agent SDK 6月独立计费上线，MCP 2026-07-28 spec 重写为无状态协议层。

## 要点
- 微软 Agent Framework 1.0（4/3 GA）：统一 .NET/Python，原生 MCP + A2A 支持
- Claude Agent SDK 独立计费（6/15）：query() 生成器 + 子 Agent 分层 + fallback 模型链
- LangGraph 1.0：per-node timeouts、DeltaChannel、v2 streaming
- Pydantic AI V2：harness-first 重构，capabilities 作为核心原语；LlamaIndex Workflows 1.0 同周发布
- Vercel AI SDK 7：三种 Agent 抽象（ToolLoopAgent / HarnessAgent / WorkflowAgent）
