# PyTorch 2.7 发布：Blackwell 支持 + torch.compile 增强
- 来源: https://pytorch.org/blog/pytorch-2-7
- 日期: 2026-07-10
- 标签: #AI编译器 #PyTorch #torch.compile #Blackwell #FlexAttention

## 摘要
PyTorch 2.7 正式支持 NVIDIA Blackwell GPU 架构（CUDA 12.8），torch.compile 新增对 Torch Function Modes 的 beta 支持，FlexAttention 在 x86 CPU 上新增 LLM first-token 处理优化。

## 要点
- Blackwell 支持：预编译 wheel 已发布，标志着 PyTorch 对新一代 GPU 的编译器栈适配完成
- torch.compile + Torch Function Modes (beta)：扩展了 compile 能覆盖的算子范围，对量化/稀疏等场景利好
- FlexAttention x86 CPU 原型：支持 PageAttention 等 LLM 推理关键算子，通过 Inductor C++ backend 实现
- Mega Cache 和 Native Context Parallel 新特性，进一步提升 LLM 训练/推理效率
- 继 2.6 支持 Python 3.13 后，2.7 持续打磨 PT2 编译器栈稳定性
