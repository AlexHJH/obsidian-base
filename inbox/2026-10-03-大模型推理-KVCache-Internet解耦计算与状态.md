# 面向 KV Cache 的「互联网」：把计算与 KV 存储解耦到跨云
- 来源: https://arxiv.org/abs/2608.01526
- 日期: 2026-08-02
- 标签: #大模型推理 #KVCache #网络 #内存层级

## 摘要
UChicago（Siddhant Ray / Nick Feamster / Junchen Jiang）的立场论文主张：agent、检索、工具调用等负载的上下文高度重叠，KV 复用机会正在把 KV Cache 变成跨云分发对象，网络应成为一等公民。

## 要点
- 现状割裂: 模型侧压缩（缩 KV）与系统侧传输优化各自演进，被传统云/数据中心边界挡住，复用收益无法在全局兑现
- 主张: 解耦「计算」与「KV 存储」，跨云跨机房放置；KV 管理按内容分发系统（CDN）范式设计——带宽、时延、价格直接决定「搬运 vs 重算」
- 需要新抽象: 通信/策略/数据发现三件套，含 lookup 服务发现可复用状态、估算传输 deadline 与可用带宽，再决定搬运、复制或不搬
- 可衔接原语: 前缀缓存（发现可复用）、KV offloading（跨层级搬）、预取与路由（放置决策）、Internet 式路由（无固定拓扑地演进）
- 对内存层级的意义: KV 成为横跨 HBM / CXL / 本地 SSD / 远端存储 / 网络 的统一寻址对象，归属与一致性域问题被推到台前
