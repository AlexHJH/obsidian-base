# WWDC26：MLX 分布式推理/训练正式化（JACCL + Thunderbolt RDMA）

- 日期: 2026-06-08

## 摘要
WWDC26 推出 MLX 跨 Mac 分布式方案：MLX + JACCL 低延迟通信 + RDMA over Thunderbolt，多台 Mac 组成集群，`mlx.launch` 一条命令即可启动分布式 MLX-LM Server。官方定位"几台桌面 Mac 取代昂贵云基础设施"，可跑万亿参数模型，并支撑纯本地 agentic AI。

## 要点
- 四层栈：MLX → MLX-LM（量化/微调）→ MLX-LM Server（OpenAI 兼容）→ agent 层（Ollama/LM Studio/vLLM）；新增 Metal 4 与 GPU Neural Accelerator 支持
- 生态信号：Ollama 0.19 起 Apple Silicon 后端切换为 MLX，M5 上较 llama.cpp Metal 快 30-60%（prompt 处理 3-4x）
- 与 [[MLX生态2026]] 衔接：分布式拼图补齐后，本地集群训练/推理成为 Mac 生态现实选项
