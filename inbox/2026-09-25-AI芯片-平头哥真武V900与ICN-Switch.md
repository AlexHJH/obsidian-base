# 平头哥真武 V900：把 scale-up 域从 128 卡推到千卡，算力天花板在芯片之间

- 来源: https://zhuanlan.zhihu.com/p/2085707168267907213 ; https://news.qq.com/rain/a/20260922A0456L00
- 日期: 2026-09-22
- 标签: #AI芯片 #阿里平头哥 #超节点 #互联 #内存语义 #ICN

## 摘要
云栖大会（9/22）平头哥发布训推一体 AI 芯片真武 V900：单芯片性能为今年 5 月真武 M890 的 3 倍，216GB 显存、1200GB/s 片间互联（M890 为 144GB / 800GB/s），FP32–FP4 全精度，2027Q1 量产；配套自研 ICN Switch 把超节点域从 128 卡推到千卡，宣称单一集群可稳定支撑 50 万卡。

## 要点
- 三个关键点定义这套超节点：**原生内存语义**（跨卡访问显存走 load/store 而非消息收发，协议栈开销大幅压缩）、**内存统一编址**（千卡显存同一地址空间，MoE 专家分布从「通信路由问题」变成「地址寻址问题」）、**千卡全带宽**（任意卡对带宽不随规模打折，百纳秒级时延）
- 设计取舍值得抄：显存 144→216GB、片间带宽 800→1200GB/s 的涨幅比算力倍数更能说明问题——两者都是为系统级扩展准备的，不是为单卡跑分
- 全栈流水线思路：超节点服务器同机集成真武 V900（算）+ ICN Switch（片间互连）+ 磐脉 920 智能网卡（国内首个内置 PCIe Switch 的 400G 卡）+ 镇岳 SSD 主控（存），未来倚天 720/730 承接调度与 Agent 场景 CPU 密集型工作
- 战略伏笔：倚天 750 将支持 ICN 片间互联总线协议 → CPU 也进入统一内存语义域，直指 Agent 时代 CPU–GPU 调度与搬运开销
- 演进节奏：V900（2027Q1）→ 真武 J900（2028Q3）；磐久超节点服务器（搭载 V900 + ICN Switch + 磐脉 + 镇岳）2027Q1 上市；灵骏 M890 超节点实例 GP9A 已对外服务，官方称国内首个跑通 2 万亿参数大模型的超节点形态算力
- 判据补充：评估一套 AI 算力除峰值算力外，还应追问三项——片间互联带宽多少、超节点域能做多大、软件能否看到统一地址空间
- 待验证：千卡超节点的实际带宽/稳定性仍需规模部署后的 benchmark，当前均为厂商口径
