# AI Agent 框架 Q2 2026：大厂入局，格局巨变
- 来源: https://alicelabs.ai/en/insights/best-ai-agent-frameworks-2026
- 日期: 2026-07-28
- 标签: #AI-Agent #Agent框架 #MCP #A2A

## 摘要
2026 Q2 是 Agent 框架史上最繁忙的季度。Microsoft 合并 Semantic Kernel + AutoGen 发布 MAF 1.0；LangGraph 1.0 新增 per-node timeouts；Google ADK 2.0 七月发布，支持五语言 graph engine；Claude Agent SDK 支持层级子 agent。

## 要点
- 选择框架的三大门槛：持久状态+HITL原语、原生MCP支持、原生A2A跨agent通信
- MAF 1.0 是目前唯一同时原生支持 MCP + A2A 的框架（.NET + Python）
- CrewAI 1.14 引入可插拔 memory/knowledge/RAG 后端，Pydantic AI V2 与 LlamaIndex Workflows 1.0 同周 GA
- 趋势：从单框架选型转向协议互通 — MCP 管工具，A2A 管 agent 间通信
