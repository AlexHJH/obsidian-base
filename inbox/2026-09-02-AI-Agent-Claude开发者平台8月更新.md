# Anthropic 开发者平台 8/27 更新：Files/Skills SDK 对齐 + 个人与服务账户密钥
- 来源: https://releasebot.io/updates/anthropic
- 日期: 2026-09-02
- 标签: #AI-Agent #Anthropic #Claude #开发者平台

## 摘要
8/27 Claude 开发者平台更新 SDK 对 files 与 skills 的行为，统一 beta 与非 beta 形态（BetaSkill 更名 BetaContainerSkill、调整技能删除行为），并在 Claude Console 新增个人密钥与服务账户密钥。

## 要点
- SDK 变更：files/skills beta 与稳定版形态对齐，BetaSkill → BetaContainerSkill，技能删除行为调整
- Console 新增 personal keys 与 service account keys，便于 workspace 级访问与账户追踪
- 同期 Claude Code 新增受限模式、跨会话消息、企业用量配额等
