# TVM Unity 并入主分支：LLM 编译成为 TVM 核心流程
- 来源: https://hyper.ai/cn/news/28318 (上海 Meetup 回顾)
- 日期: 2026-07-01
- 标签: #AI编译器 #TVM #Unity #Relax #MLIR #LLM编译

## 摘要
TVM Unity（Relax + TIR）经过一年多迭代，近期并入 Apache TVM 主分支成为默认编译流程。MLC LLM 已基于 Unity 构建 LLM 部署引擎，支持浏览器/手机/GPU 多平台。

## 要点
- Relax(高层图IR) + TIR(Tensor级IR) 合并为 Graph-TIR 统一编程范式，专为动态 shape 和 LLM 设计
- 已有 TVM Unity Connection RFC，连接 FFI/TensorIR/MetaSchedule/Relax 四大组件
- MLC LLM 基于 Unity 实现跨平台 LLM 部署（WebGPU/iOS/Android/GPU）
- Hexagon-MLIR（高通）基于 MLIR 编译 Triton→NPU，主打端侧统一 IR 生态
