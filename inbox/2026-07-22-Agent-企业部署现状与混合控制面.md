# 企业 AI Agent 部署现状：85% 在试点，5% 上了生产
- 来源: https://venturebeat.com/ai/agentic-orchestration-enterprise-ai-organizations-have-a-deployment-problem-not-a-platform-problem-and-most-are-calling-chatbots-agents
- 日期: 2026-07-22
- 标签: #AI-Agent #企业部署 #Agent编排 #MCP

## 摘要
VentureBeat Pulse 调研 101 家企业：85% 在试点 Agent 但仅 5% 上生产；多数"Agent"实际只是 Chatbot 包装器。Anthropic Claude 是企业首选平台，51% 预计年底采用混合控制面（provider native + 外部编排），供应商锁定是最大担忧（35%）。

## 要点
- 模型引力决定平台选择：Claude 大幅领先，可靠多步执行是核心评估维度
- 实时 token 成本控制仍是盲区，大多数企业缺乏 fiscal control 机制
- Amazon AGI 实验室提出"实习生"管理框架：consistency/robustness/predictability/safety 四维可靠性
- 趋势：单 Agent wrapper → 多工具自纠正架构，但落地远慢于预期
