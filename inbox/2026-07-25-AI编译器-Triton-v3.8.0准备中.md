# Triton v3.8.0 准备中：Blackwell 适配与 Pipeliner 重构
- 来源: https://github.com/triton-lang/triton/issues/10907
- 日期: 2026-07-25
- 标签: #AI编译器 #Triton #Blackwell #GPU

## 摘要
Triton v3.8.0 发布 tracker 已于 7 月中旬启动。本版本重点包括 Blackwell SM120 架构支持、Pipeliner 调度改进，以及修复 TMA Tensor Descriptor 在 Blackwell 上的 gather/load 与 tl.dot 不兼容问题。

## 要点
- SM120 cluster lowering 修复：此前拒绝合法 multi-CTA kernel
- Pipeliner 新增 conditional load producer 正确下沉到 consumer stage
- Tensor descriptor + tl.dot 在 K 非 BLOCK_SIZE_K 倍数时产错修复
- 社区讨论 fork-safe Triton 方法论，支持多进程推理场景
