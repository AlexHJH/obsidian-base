# P-D 分离推理：从 NVIDIA 扩到多厂商 GPU + AWS 落地 vLLM
- 来源: https://arxiv.org/html/2509.17542v1 ; https://aws.amazon.com/blogs/machine-learning/disaggregated-prefill-and-decode-for-llm-inference-on-sagemaker-hyperpod
- 日期: 2025-09（arXiv v1）
- 标签: #大模型推理 #PD分离 #KV-Cache #vLLM

## 摘要
Prefill（算力受限，决定 TTFT）与 Decode（带宽受限，决定 ITL）共置会互相干扰——长 prompt 会拖住所有并发请求的 token 生成。P-D 分离（DPD）把两阶段放到独立 GPU 池、用高速互联搬运 KV，让每个池各自对准自己的瓶颈。新工作把 P-D 从 NVIDIA 单厂商扩到多厂商 GPU，并给出 chunked prefill 提升「decode 捎带率」的具体机制。

## 要点
- 核心机制：chunked prefill 让单个 prefill 请求能拼出多个 decode max batch，最大化「可捎带 decode」的覆盖
- 落地形态：AWS SageMaker HyperPod 用 vLLM 实现 DPD，池间走 EFA RDMA（而非 NVLink），把耦合从专有硬件解到标准网络
- 谱系：Splitwise（map-reduce 式阶段拆分）、DistServe（OSDI'24，goodput 优化）、Mooncake（KV 中心化架构）、MemServe（弹性内存池）
- 判据：DPD 不是万灵药——只有长 prompt + 高并发共置才会明显收益，池间 KV 搬运带宽是新的瓶颈
