# K1/K3 上游变更与回归档案

每条记录要回答：影响哪个后端、最小复现是什么、哪一级验证通过、还有什么没测。区分公开源码与组织内部材料；未获授权的日志、路径、客户样本和性能数字不进入同步仓库。

## 优先跟踪

| 方向 | 记录口径 |
|---|---|
| RVV／IME／量化内核 | Q4_0/Q4_1 的 256 特化和派发边界、未对齐 fallback、K1 与 K3 指令集差异、编译器 flags；对照通用 CPU 输出和真机性能 |
| MTP／状态回滚 | 同 prompt 开/关 MTP 逐 token 校验；分开记录 draft、验证、回滚、提交数及接受率；覆盖语言和 prompt 类型，不把单样例归因到语言 |
| Triton／TLE | `smt_rvisa` tile lowering、ABI 和布局兼容、编译产物与 cache key；对照紧凑尾块和含 padding 的边界测试 |
| 测试与依赖 | 固定上游 tag/fork commit、编译器、flags、模型/量化和运行平台；编译、QEMU、板测、端到端和 CI 状态各自标记 |
