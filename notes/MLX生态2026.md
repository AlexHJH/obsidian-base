## WWDC26: 分布式推理 + 本地 Agent
苹果展示 MLX 四层 Agent 栈：MLX(数组框架) → MLX-LM(模型) → MLX-LM Server(OpenAI 兼容) → Agent。Thunderbolt RDMA 实现多 Mac 分布式推理，4×M3 Ultra 跑 27B 吞吐近 3x，全本地 Agentic AI 栈支持离线运行。

## Ollama 0.19 全面拥抱 MLX
Apple Silicon 推理后端从 llama.cpp 切换至 MLX，MoE 模型 decode 从 3.19 → 23.39 tok/s（~7x）。自动路由 GGUF→llama.cpp、safetensors→MLX。Rapid-MLX 作为替代品在 M3 Ultra 上再快 2-4.2x。
- int4 量化基准：prefill 1851 tok/s / decode 134 tok/s，相比 llama.cpp 后端约 2x 提速（整理自 [[inbox/2026-06-19-Ollama切换MLX后端]]）

## M5 神经加速器接入 MLX
整理自 [[inbox/2026-06-19-MLX接入M5神经加速器]]
- Apple ML 团队在最新 macOS beta 启用 MLX 对 M5「神经加速器」的支持
- 神经加速器位于 M5 GPU 内，专职 GEMM 矩阵乘法（LLM 推理核心算子）
- 官方在 24GB M5 MacBook Pro 对不同规模/架构 LLM 基准，与同配 M4 对比
- 软硬协同推进端侧推理性能，关联 [[AI芯片推理硬件2026全景]]

## 趋势
- MLX 从框架升级为生态：从单机推理 → 分布式 → Agent 全栈
- Ollama 生态兼容意味着 MLX 进入千万级用户设备
- Apple Silicon 本地推理体验接近云端，隐私保护是差异化优势
