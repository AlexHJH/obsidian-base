# 3D键合与钼材料深度调研

> 💡 **为什么关注这个赛道？** 混合键合（Hybrid Bonding）是后摩尔时代先进封装的核心技术，钼（Mo）正在从"替代钨的候选材料"升级为"3D堆叠芯片的必需材料"。2026年是钼半导体产业化的元年。

---

## 一、3D键合技术全景

### 1.1 什么是混合键合

混合键合是一种**无凸块互连技术**——不采用焊料或黏合剂，通过铜-铜直接接触和介电层分子键合，实现芯片的3D堆叠。

| 对比维度 | 传统微凸块 | 混合键合 |
|----------|:---------:|:-------:|
| 互连间距 | 40-55μm | **<10μm（目标2-3μm）** |
| I/O密度 | 5-10 个/mm² | **10,000+ 个/mm²** |
| 单位能耗 | 0.5 pJ/bit | **0.05 pJ/bit** |
| 堆叠高度 | 每层有数十μm间隙 | **近乎零间隙** |
| 键合精度 | 10-20μm | **100-200nm（目标<50nm）** |

### 1.2 为什么混合键合变得不可回避

**三大结构性驱动力：**

1. **HBM堆叠层数暴增**：HBM4→16层，HBM5→20层；传统TCB在物理上无法满足JEDEC封装高度规范（720μm），2028-2029年混合键合成HBM5的必需选项
2. **AI芯片互连密度需求**：GPU/ASIC与HBM间的带宽墙，需要超精细间距互连突破
3. **逻辑芯片3D堆叠**：台积电SoIC、Intel Foveros Direct 已商用；Apple、AMD、NVIDIA、Broadcom 均为客户

### 1.3 两种技术路径

| | W2W (Wafer-to-Wafer) | D2W (Die-to-Wafer) |
|---|---|---|
| **方式** | 整片晶圆一次性键合 | 逐颗芯片拾取放置键合 |
| **精度** | <50nm | 100-200nm |
| **产能** | 高（分摊成本低） | 低（目前最大瓶颈） |
| **应用** | CIS、3D NAND | HBM、逻辑堆叠、Chiplet |
| **成熟度** | 索尼2016年已量产 | Intel/TSMC商用初期 |
| **市场增速** | CAGR 16% | **CAGR 69%**（弹性更大） |

## 二、混合键合工艺与核心挑战

### 2.1 九步工艺流程

1. PECVD沉积介电层（SiCN/SiO₂）
2. 光刻定义铜焊盘位置 → 蚀刻通孔
3. CVD/PVD沉积阻挡层+铜籽晶层 → 电化学填铜
4. **CMP平坦化**（关键步骤）→ 介电层粗糙度 <0.5nm，铜焊盘凹陷 ~5nm
5. 等离子体活化表面（N₂/O₂）
6. 清洗去除颗粒
7. 精密对准键合（100-200nm误差）
8. 室温预键合（~1MPa压力，介电层先贴合）
9. 退火（200-350°C，2小时）→ 铜热膨胀完成金属键合

### 2.2 四大竞争焦点

| 挑战 | 要求 | 现状 |
|------|------|------|
| **平坦度** | 介电层 <0.5nm，铜 <1nm | CMP+AI终点检测 |
| **洁净度** | 零容忍（1μm颗粒→10mm空洞） | 去离子水+超声+大气等离子体 |
| **对位精度** | <100nm（D2W目标<50nm） | EVG SmartView双镜头；Intel/CEA-Leti流体自对準降至200nm |
| **吞吐量** | 商业化关键 | D2W 1000-2000 UPH，仍是瓶颈 |

## 四、钼在3D键合中的关键角色

> ⭐ **核心论断**：钼正在从"钨的替代者"升级为3D堆叠芯片的"必需材料"。3nm以下逻辑芯片 + 300层以上3D NAND + HBM4/5的物理极限，倒逼钼材料全面替代钨。

### 4.1 为什么是钼？物理优势碾压钨

| 参数 | 钨 (W) | 钼 (Mo) | 优势 |
|------|:---:|:---:|------|
| 体电阻率 | 5.6 μΩ·cm | 5.3 μΩ·cm | 略优 |
| 电子平均自由程 | 较长 | 极短 | 纳米薄膜电阻低30-40% |
| 阻挡层需求 | 必须（TiN等） | 无需 | 与介电材料直接粘附 |
| 高深宽比填充 | 困难（易空洞） | 完美（ALD均匀填充） | 300层+堆叠唯一解 |
| 抗电迁移 | 一般 | 极强 | AI高负载场景必需 |
| 热稳定性 | 好 | 更好 | 2623°C熔点 |

### 4.2 三大应用场景

**场景一：3D NAND超高堆叠 — 字线金属化（最大增量）**

- SK海力士官宣：375层 3D NAND采用钼金属字线，2026年底量产
- 传统钨工艺在300层+时：填充空洞→良率崩塌；厚重阻挡层→空间浪费
- 钼方案：无阻挡层+ALD完美填充，300→500→1000层堆叠的唯一工艺路径
- 三星、美光同步导入

**场景二：先进逻辑芯片 — 铜互连替代/混合金属化**

- 铜在<10nm线宽下电阻率急剧上升（电子散射效应）
- Lam Research 验证：钼混合金属化方案降低总互连电阻56%
- 钼通孔 + 铜导线的混合方案：保留铜的低电阻优势，用钼解决通孔瓶颈
- AMAT、Lam Research 均已推出钼ALD沉积设备（Altus系列）

**场景三：混合键合界面 — MoS₂钝化层**

- 2025年最新突破：在混合键合O₂等离子体处理前，用PECVD硫化Mo膜形成超薄MoS₂阻挡层
- 阻止铜溅射→消除腔体污染（键合工艺长期顽疾）
- 键合后Cu离子在MoS₂中形成导电细丝→自动建立电气连接（忆阻器机制）

### 4.3 技术路线：以钼代钨已不可逆

传统路线（已触顶）：W + TiN阻挡层 → 300层极限 → 填充空洞 / 良率崩塌
新路线（不可逆）：Mo ALD（无阻挡层） → 500层+ → 完美填充 / 低电阻 / 高良率

全球头部厂商已统一路线：SK海力士2026年底量产钼字线375层NAND；Lam Research Altus系列Mo ALD量产；AMAT Insepra SiCN + Catalyst CMP支持钼工艺；三星V10 NAND导入钼金属化；美光跟进导入。

## 六、总结与趋势判断

### 6.1 三重拐点共振

| 拐点 | 时间 | 信号 |
|------|:---:|------|
| **技术拐点** | 2026年 | 3nm以下逻辑 + 300层+ NAND → 钨/铜触及物理极限，钼是唯一解 |
| **量产拐点** | 2026年底 | SK海力士375层钼字线NAND量产；全球大厂统一技术路线 |
| **需求拐点** | 2026-30年 | AI算力低功耗 + 超高堆叠存储 → 钼需求从0到1、从1到10爆发 |

### 6.2 关键结论

1. **混合键合是3D堆叠的"EUV时刻"**：如同EUV光刻机定义了先进制程，混合键合正在定义先进封装的标准。设备市场2022-2029年翻倍以上增长。

2. **钼是混合键合时代的"新材料支柱"**：混合键合设备 + 钼金属化工艺 = 3D堆叠芯片的量产基础。钼不再是"替代选项"，而是"唯一选项"。

3. **中国设备商正在追赶**：拓荆科技、迈为股份、芯慧联已实现混合键合设备出货，大基金三期明确注资三维集成设备方向。但BESI/EVG在精度和产能上的领先优势仍需时间追赶。

4. **投资逻辑从周期→成长**：钼从传统工业小金属，彻底转型半导体科技刚需材料。高端半导体级钼产能稀缺、认证壁垒极高，头部企业将长期受益。
