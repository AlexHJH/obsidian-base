# MI355X 推理优化：13 周 19x 吞吐量提升

- 来源: [[inbox/2026-06-13-MI355X-推理优化19x]]
- 标签: #AMD #MI355X #推理优化 #MoE #SGLang #AITER

## 数据
Qwen3.5-397B-A17B 在 MI355X 上 SGLang FP8 推理吞吐：
- 2026-02-20: 192 tok/s/GPU (v0.5.8)
- 2026-04-16: ~2,400 tok/s/GPU (v0.5.10, 12.5x)
- 2026-05-19: 3,660 tok/s/GPU (v0.5.12, **19.0x**)

## 优化来源
- AITER MoE Kernel (三轮): expert 调度 + shared memory 布局 + wave 并行 → ~12.5x
- TP 度调整 (8→2/4): 降低通信开销，优化 expert 负载均衡 → ~1.5x
- ROCm 驱动 + AITER runtime 升级 → ~1.5x

## 方法论启示
- MoE 推理瓶颈在 kernel 而非硬件 — 天花板远未触及
- TP 度不是越大越好 — MoE 场景有 tradeoff
- AMD 软件栈快速追赶，AITER+SGLang 已达可用级
- 芯片发布时性能 ≠ 成熟后性能
