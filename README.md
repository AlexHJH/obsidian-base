# 知识库

> 由泡泡啦定期维护 · Obsidian 编辑 · GitHub 同步

## 目录结构

| 目录 | 用途 | 谁写 |
|------|------|------|
| `inbox/` | 值得跟进的新资料 | 泡泡啦 |
| `notes/` | 整理后的永久笔记 | 泡泡啦 + 你 |
| `daily/` | 日记/随手记 | 你 |
| `interests/` | 关注的主题清单 | 你（泡泡啦以此为搜索线索） |
| `templates/` | Obsidian 模板 | 你 |
| `chip-map/` | [[AI 芯片地图]]：国内外、已发布与路线图、规格和一手来源 | 泡泡啦 + 你 |

## 工作流

1. 泡泡啦每周六 10:00（UTC+8）扫描 `interests/`；无实质变化不写。
2. 有证据的进展写回对应专题，待核与已确认分开。
3. 通过 GitHub 同步私有网页；你可继续用 Obsidian 编辑。不自动上传未授权内部材料。
